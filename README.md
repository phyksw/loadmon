# add_tool — 팀취합본만으로 로드율 재계산 (LM20 · LM24 판 무관)

LoadMonitor 팀 폴더에 **붙여 넣고 bat 을 실행하는 단독 도구**입니다. 어느 판(LM20 / LM22 이후 v3 계열)의
폴더에 붙여도 되고, 저장소의 다른 코드를 임포트하지 않습니다. `lm24-v4` 브랜치에도 같은 파일이 들어 있지만,
판과 무관하게 쓰는 도구라 이 브랜치에 따로 둡니다.

| 파일 | 역할 |
|---|---|
| `team_recalc.py` | 재계산기 본체(파이썬 3.11+, 표준 라이브러리만) |
| `LoadMonitor24-팀로드율재계산.bat` | 더블클릭 실행기 — 동봉 `python\` → 상위 `..\python\` → PATH python → `py -3` 순으로 파이썬을 찾는다 |
| `tools/check_recalc.py` | 계약 시험(합성 팀 폴더를 임시로 만들어 산식·분모·결손 처리·무해성을 검사) |

## 왜 필요한가

팀에는 LM20 으로 올린 사람과 LM24 로 올린 사람이 섞여 있고, 두 판의 로드율 산식(PC 하한 게이트·점심 차감·수동 신호
다리·공휴일표·분석 시점 절단)이 달라 **같은 사람이 판에 따라 수십 p 갈립니다**. 개인 PC 의 원자료(PC 가동·샘플러·달력)는
팀에 올라오지 않으므로 개인별 재분석은 불가능합니다.

팀에 남은 것은 인별 폴더의 두 파일 — `signals_<기간>.csv`(신호 시각·출처·가중치)와 `mm_meta_<기간>.json`(그 판의 일별
투입·월별 부재) — 이고, 두 판이 **글자까지 같은 헤더·키**로 올립니다(실측). 이 도구는 그 둘만으로 모든 인원을
**하나의 산식·하나의 달력**으로 다시 잽니다.

## 쓰는 법

1. `team_recalc.py` 와 `LoadMonitor24-팀로드율재계산.bat` 을 **팀 폴더**에 복사합니다 — 인별 폴더(`<이름>\member.json`,
   `signals_*.csv`, `mm_meta_*.json`)가 있는 곳: 팀 서버 PC 의 `teamdata\` 또는 팀 공유폴더.
   LoadMonitor24 설치 폴더에 두고 실행해도 `teamdata\`·`config.teamShareDir` 를 자동으로 찾습니다(본인 `report\` 는 인원으로 보지 않음).
2. bat 을 더블클릭합니다. 기존 `team_report.html` 등은 **건드리지 않고** 새 파일 3개가 생깁니다:
   `팀로드율_재계산_<시각>.html`, `..._월별.csv`, `..._과제.csv`. 다시 실행하면 새 시각으로 또 생깁니다.
3. 팀 폴더를 인자로 줄 수도 있습니다(끝의 `\` 는 빼세요):
   ```bat
   LoadMonitor24-팀로드율재계산.bat "\\서버\팀공유\LoadMonitor"
   ```
   지정한 폴더가 없거나 인별 폴더가 없으면 **실패**합니다(다른 폴더로 조용히 바꾸지 않습니다).
   내장 연도표(2025~2027 설·추석·대체공휴일·선거일)에 없는 임시 휴일은 `--holidays 2026-11-02` 처럼 덧붙입니다.

## 보고서 읽는 법

- **C3(권장)** — 능동 흔적(산출물·발신·회의·샘플러·수동기록)이 있는 평일은 `max(근거 구간, 8h + 09~18 밖 능동 세션 초과)`,
  능동 없는 평일은 근거 구간 그대로(수신 메일만 있는 날에 8h 가 붙지 않음), 주말·공휴일은 능동 있는 날만.
  합성 3유형(야근·회의·조용) 실측에서 참값 대비 −7/−3/−16p 로 세 유형 모두 아래·방향 일정.
- **A** = 능동 평일 8h(출근일 하한) · **B** = 근거가 덮은 시간(LM24 세션 규칙 ∪ 회의 구간, 샘플러·수동기록은 하한) ·
  **D** = 그 판이 계산한 원값(비교 기준선).
- **가용** = 통일 달력 평일수 − 월별 부재, **분석 시점 이후 평일 제외**(기간 종료 전에 올린 자료는 '기간 미완' 비고).
  로드율 = 투입시간 ÷ (8h × 가용일). 가용 0 인 달은 비율·팀 합계에서 제외.
- **판 배지**(LM20 추정 / LM24 / 판 불명), **무흔적 평일(−부재)**, **C3−D** 를 함께 봅니다. C3−D 가 크게 양수면 원 판이 PC 없이
  세션만 재었을 가능성, 음수면 원 판이 수동 신호 다리·PC 가장자리로 더 잡았거나 **C3 가 보지 못하는 PC 가동·샘플러 구간을
  원 판이 실측한** 경우입니다 — C3 는 하한 성격이라 −15p 안의 음수는 판 차이로 단정하지 마세요.
- signals 를 읽을 수 없는 인원(0바이트·Excel 로 ANSI 재저장·열 이름 변경·따옴표 불균형)은 0% 로 섞이지 않고 A·B·C3 가
  빈칸 + 비고로 나옵니다(cp949 파일은 그대로 읽습니다). mm_meta 가 없는 인원은 D 가 빈칸입니다.

## 한계

PC 가동 구간 · 샘플러 구간(총 분만) · 연차 '일자'(월 합계만) · 회의 수락 여부 · 표본화 전 파일 시각은 팀에 올라오지 않아
어느 산식도 복원하지 못합니다. 능동 흔적이 없는 평일은 8h 가 붙지 않아 C3 = 근거 구간뿐입니다.

## 시험

```bat
python tools\check_recalc.py
```
합성 팀 폴더(LM20 형식·LM24 형식·기간 미완·결손 4종·가용 0 달·cp949·겹치는 기간)를 임시로 만들어 판 무관(A·B·C3 동일)·
손으로 계산한 산식값(189.0h)·분석 시점 절단(가용 11.09일)·기존 보고서 무변경·같은 초 재실행 회피·없는 인자 실패 등을 검사합니다.
