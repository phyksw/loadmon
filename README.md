# AX 3대 과제 리소스 플랜 (2027)

기준일 2026-10-22. AL-1, VV-1, VV-3 를 **새 인원 3명**으로 2027년에 어디까지 할 수 있는지 정리한 계획입니다.
외주 없이 사내에서 직접 개발하고, 운영은 혼합안(개발은 바이브 코딩, 운영은 LangGraph 하나로 자료 등급에 따라 나눠 보냄)을 기준으로 했습니다.
사람 이름과 팀 이름은 넣지 않았습니다. AX 담당은 A와 B, DRI 는 C엔지니어(AL-1, VV-3)와 D엔지니어(VV-1)로 적었습니다.

## 바로 보기

`AX_리소스플랜_2027.html` 을 브라우저로 엽니다. 휴대폰에서도 볼 수 있습니다.
맨 위에 결정 기한, 핵심 숫자, 용어 풀이가 있고 아래에 탭 세 개가 있습니다.

- **필요한 능력**: 누가 언제 일하는지, 새 인원 수에 따라 달라지는 것, 역할별 필요한 역량, 개발 방법
- **예상 일정**: 과제별 일정, 2028년으로 넘기는 일, 사람을 구하는 일정, A와 B 의 월별 부하, 로직 점검
- **인프라 구축**: 운영 방법(1안, 2안, 혼합안), 온프렘 서버와 투자심의 일정, 비용

## 핵심 숫자

| 항목 | 값 |
|---|---|
| 새로 들이는 사람 | 3명: AI 엔지니어 1명, CAE 자동화 엔지니어 1명, MLOps 엔지니어 1명. 경력 채용과 외주는 없음 |
| 2027년에 하는 일 | 95 MM (월평균 7.9명분, 기존 인력 시간 포함) |
| 빌려 쓰는 시간 | 27.6 MM (겸직, DRI 팀 직접 수행, 전사 지원, A와 B 의 개발 참여) |
| 2028년으로 넘기는 일 | 작업 15개, 41 MM |
| 2027 마일스톤 (14개) | 모두 지킴 10개, 일부만 지킴 1개, 2028년으로 3개 |
| 2027 증분 현금 | 8.0억 (나쁘게 잡으면 14.5억, 좋게 잡으면 3.0억) = 투자 6.7억 + 운영 1.3억 |
| 운영안별 같은 범위에 필요한 새 인원 | 1안 4명, 2안 4명, 혼합안 3명 |

## 결정 기한

- **~ 2026-11-15** 새 인원 3명 확정 (모두 사내 전환): AI 엔지니어 1명, CAE 자동화 엔지니어 1명, MLOps 엔지니어 1명
- **~ 2026-11-15** LLM 브리지 확보 (전사 공용 GPU 또는 빅플랜 GPU 먼저 배정)
- **~ 2026-11-30** 온프렘 투자심의 기안, 운영 방식(혼합안) 결정, 바이브 코딩 도구 보안 승인 신청
- **~ 2026-12-15** 빌려 쓰는 시간 확약 (겸직, DRI 팀 직접 수행, 전사 지원, A와 B)
- **~ 2026-12-31** 2028년으로 넘기는 작업 15개 확정, 원장과 로스터 고치기 (Gate 1)

## 다시 계산하기

```
cd plan2027
python scope_fit.py --heads 3      # 새 인원 3명으로 할 수 있는 범위 찾기 → design/final/sourcing_3p.json, scope_3p.json
python scope_fit.py --heads 4      # 비교용 4명 → sourcing_4p.json
python options_3p.py A             # 1안을 같은 범위로 (2안은 B)
python build_page.py --draft       # 페이지 만들기 → AX_리소스플랜.html, AX_리소스플랜_standalone.html
```

- 넘기는 순서는 `scope_fit.py` 의 ORDER 입니다(위가 먼저 넘어감). 선행 작업을 넘기면 뒤 작업도 함께 넘기고, 다시 넣을 때는 선행 작업까지 묶어서 넣습니다.
- 전제를 바꾸는 곳: `design/final/method_3p.json`(바이브 코딩 효과, 외부 MCP, 운영안, 리드타임과 적응 기간), `rates.json`(단가), `model27.py`(작업, 일정, 공급).
- `sourcing_opt.py` 는 새 인원 한도 안에서 사내 조달 조합(전환, 겸직, DRI 팀 직접 수행, A와 B 의 개발 참여 등)을 고릅니다.
- `inputs/ledger_2027.json` 은 원장과 로스터에서 2027 마일스톤 14개와 Agent 13개만 뽑은 사본입니다.
- `design/final/scenarios.json` 은 이전 안(새 인원 10명, 전체 범위)의 비교 기록입니다.
