## 이번 자료에서 명확히 한 내용

메일과 Teams에서 읽는 항목, PC에 보관하는 원자료, 가져오지 않는 범위를 구분했습니다. PC 가동 기록과 프로그램별 사용시간도 서로 다른 정보로 설명했습니다. 분석에서 제외하는 처리, AI에 보낸 뒤 적용하는 판정, 팀에 전달할 때 하는 검사도 각각 표시했습니다.

사용자 확인에 따라 Graph API는 현재 미사용으로 빗금 처리했습니다. 활동 샘플러와 이에 따른 새 프로그램별 관측 시간은 제출 범위에서 제외했습니다. 이번 작업은 문서 수정이며, 기존 제품 코드나 예약 작업, 과거 자료를 제거한 배포본의 검증은 아닙니다. 실제 정리 여부는 운영 확인표의 SEC-04에서 확인하도록 했습니다.

현재 범위의 합성 시험은 수집과 신호 41개, AI와 전송 10개입니다. 예상 동작을 재현한 결과이며 보안 통과율을 뜻하지 않습니다. 일부 등록 단어의 신호 제외는 확인했지만, 사적인 대화나 고객사명, 중요정보를 모두 찾아 가리는 기능은 확인되지 않았습니다.

## 검토 범위와 한계

작성, 독립 검토팀의 질문, 근거 답변, 수정, 재검토를 반복했습니다. 운영 담당자가 확인할 사항은 실제 기능과 환경, 팀 접근 및 전송 보호, Microsoft 365 정책, 정보의 허용 범위와 정정, 저장 보호, 보존 및 파기의 6개 항목으로 정리했습니다.

실제 회사 계정이나 업무 자료, 운영 서비스를 검증한 결과 또는 보안 승인서는 아닙니다. PDF는 페이지별 시각 검토와 수정 페이지 재검토를 수행했습니다. HTML은 문서 구조, 링크, JavaScript 구문과 자체 SVG 도형을 검사했습니다. 브라우저 전체 화면은 로컬 파일 접근 제한으로 확인하지 못했습니다.
