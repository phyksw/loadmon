## 요약

1. **1인 비용**: Claude Code 공식 비용 문서에 따르면 기업 배포 평균은 **활성일 1일 $13, 월 $150~250**이고, **사용자의 90%가 활성일 $30 미만**이다(2026-04-15에 $6/$12에서 올려 잡음). 계획값(좌석 + 종량)은 **1인 월 보수 $650 / 기준 $280 / 낙관 $140**이며, 기준값은 Enterprise 좌석 $20에 활성일 20일 × $13을 더한 값이다. 좌석 가격은 도구마다 크게 다르지 않고, 실제 비용은 토큰 사용량이 정한다.
2. **조달 경로**: LG CNS가 2026-06-09 앤트로픽과 **"LG그룹 전 계열사에 적용 가능한" Claude Enterprise 통합 계약**을 맺었다. 이노텍은 새 공급사를 심사받는 대신 그룹 계약에 들어가 사내 사용 범위만 승인받는 길이 있다(기간 단축 효과는 추정, 계약 조건은 미확인).
3. **반출 통제**: 상용 약관(Team, Enterprise, API, 클라우드)에서는 학습에 쓰지 않고, 표준 보존 기간은 30일이다. ZDR은 Enterprise에서 별도 승인을 받아야 한다. **Compliance API가 Claude Code 로컬 세션 기록을 기본 6년 보관**하므로 조직 보존 기간을 따로 설정해야 한다. 한국 안에서 처리하는 경로는 **Bedrock 서울 in-region(2026-09-29부터, Opus 5, Sonnet 5만)**뿐이고, Anthropic 직접 API에는 한국 처리 옵션이 없다.
4. **로컬 모델 연결**: 기술적으로는 된다. vLLM `/v1/messages`(2025-11), Ollama v0.14+(2026-01), llama.cpp에 `ANTHROPIC_BASE_URL`로 붙인다. 다만 Anthropic은 공식 문서에서 **"게이트웨이를 통한 비-Claude 모델 라우팅은 지원하지 않는다"**고 밝힌다. 실제로 Claude Code를 업데이트했다가 vLLM 연결이 깨진 사례(v2.1.154, 2026-05)도 있다. 그래서 C3 런타임은 **LangGraph처럼 특정 모델에 묶이지 않는 구조로 만들고 버전을 고정**하는 것이 맞다.
5. **망분리**: 가능한 조합은 (a) Claude Code(내부 미러 설치, 버전 고정, 비필수 트래픽 차단, `allowedProviders`)와 사내 vLLM, (b) Copilot CLI BYOK와 `COPILOT_OFFLINE=true`, (c) 오픈소스 하네스(opencode, OpenHands, Qwen Code, Cline 등)와 vLLM이다. **Cursor는 요청이 Cursor 서버를 거치기 때문에 망분리 환경에서 쓸 수 없다.**
6. **권장안**: **C안(혼합)**. 개발(바이브 코딩)은 Claude Enterprise로 하고, 실행(13개 Agent)은 LangGraph 모델 라우터로 C3는 로컬 vLLM에만, C0~C2는 API로 보낸다. 게이트웨이 구축 공수는 **초기 보수 5 / 기준 3 / 낙관 1.5 MM**, 정보보안 승인 기간은 **보수 6 / 기준 3 / 낙관 1개월(추정)**이다.

## 8. 운영 방법 1안과 2안 비교와 하네스 선택

### 8-1. 1안(바이브 코딩 하네스 + LangGraph 투트랙, API) vs 2안(온프렘 로컬 LLM으로 관리)

| 항목 | 1안: Claude Code 하네스로 관리 + 연결이 안 될 때는 LangGraph/LangChain + API | 2안: 온프렘 로컬 LLM으로 관리 | 근거 |
|---|---|---|---|
| 처리 가능한 데이터 등급 | C0~C2만. **C3는 API로 처리 불가** | C0~C3 전부 | 과제 전제 |
| 개발 생산성과 품질 | 최상위 상용 모델 + 공식 기능(서브에이전트, Skills, Hooks, MCP, `-p`, Agent SDK)을 모두 씀 | 오픈 모델은 품질 차이가 있음(6-3). Claude Code + 로컬은 공식 지원 밖 | 3장, 6장 |
| 쓸 수 있는 시점 | 계약 직후(그룹 계약이 있으면 1~3개월, 추정) | **'27.7 서버 가동 이후** | R0 |
| 1인 월 비용 | 140 / 280 / 650 USD | GPU는 이미 예산에 있음. 추가 비용은 운영 공수(11장) | 2장 |
| 운영 부담 | 낮음(관리형). 투트랙이라 코드 경로가 둘이 되고 유지보수가 늘어남 | 높음(서빙과 모델 교체와 버전 고정과 용량). GPU를 13개 Agent와 나눠 써야 함 | 추정 |
| 주요 위험 | 정책상 반출 범위 위반(C3가 섞여 들어감), 공급사 약관 변경 | 품질 부족으로 바이브 코딩 효과가 떨어짐, 버전 변화로 연결이 깨짐 | 4-3 |
| 판단 | **개발(빌드) 평면**에 적합 | **C3 실행(런타임) 평면**에 적합 |, |
