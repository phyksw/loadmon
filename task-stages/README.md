## 로직 검토 — 단계 순서는 셋 다 맞고, 고칠 연결은 7가지

1. **MBSE(VV-3) 1단계를 지금 시작한다.** AL-1·VV-1 4단계의 ‘목표 성능’과 ‘RFQ 판정 기준’은 VV-3 요구-검증 추적표가 공급한다.
2. **VV-1 2단계 광학은 AL-1 광학 플러그인(’28.10)보다 1년 이르다.** ’27에는 광학 설계 도구 결과를 직접 읽는 브리지로 시작한다.
3. **조립 전 판정은 하나로.** VV-1 3단계와 VV-3 3단계를 하나의 VP 판정(’28.6)으로 묶는다.
4. **실측 대조를 앞당긴다.** VV-1 엔진의 첫 실측 대조를 ’28.6에서 ’27.3(벤치 5~8셀)으로 옮긴다.
5. **PLM 조회 연결은 한 번 만든다.** VV-3가 읽기 전용으로 만들고(’28.1) AL-1 3단계가 같이 쓴다.
6. **AL-1 4단계 ‘스스로 개선(RSI)’ 범위를 정한다.** 결과·채택 기록으로 탐색 전략·템플릿·대리모델을 갱신하는 데까지 하고, 최적화기가 주도하며 사람이 채택한다.
7. **사람이 먼저 걸린다.** 4묶음 4.0명 기준으로 계획된 일이 약 2배라서, ’28 범위와 인원은 ’27.6.30에 정한다.
