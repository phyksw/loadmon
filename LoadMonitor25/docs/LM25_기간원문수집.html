LOADMONITOR 25 · v25.7 · 2026-09-30

기간 안의 메일·대화를
어디까지 읽었는지 확인합니다.

서버 조회 · 앱 저장소 · 내보내기 파일을 연결했습니다.
원문을 수집하는 범위와 AI가 해석하는 범위를 분리합니다.

모든 회사 PC에서 누락 0건을 보장하는 배포본은 아닙니다.
서버 접근이 차단되고 앱·내보내기에도 원문이 없다면 그 내용을 복원할 수 없습니다. 이 문서는 구현 설명이며, 사용자의 회사 계정에서 실행한 성공 보고가 아닙니다.

1. 왜 같은 계정인데 PC마다 자료가 다를까요?

코드에서 확인한 두 결함을 고쳤습니다. 기본 저장소만 읽어 다른 계정·PST가 빠지던 문제, 이동된 발신 메일의 기간을 수신 시각으로 판단하던 문제입니다. 실제 다른 PC에서 발생한 원인이 이것뿐인지는 확인하지 못했습니다.

2. 세 경로에서 실제로 읽는 내용

A · 서버 원문

Graph API

메일: 기본 사서함의 모든 메시지 페이지를 수신·발신 시각으로 조회.

Teams: 접근 가능한 채팅, 추가 승인 시 가입 팀의 채널·답글까지 조회.

승인된 앱 ID + 읽기 권한 필요.
Copilot 라이선스는 필요 없음.
B · 앱 저장소

기존 Outlook

모든 연결 저장소와 하위 폴더, 이미 열어 둔 PST를 순회.

선택한 MSG는 Outlook의 파일 열기 기능으로 읽기.

기존 Outlook의 COM 기능 필요.
새 Outlook만으로는 사용할 수 없음.
C · 내보낸 원문

파일 가져오기

메일 EML/MBOX, Teams Graph chatMessage JSON.

공통 지정 CSV/JSON/JSONL. 날짜·본문·대화 ID·원본 ID·건수 대조.

승인된 원문 내보내기가 필요.
임의 HTML·요약문은 지원 형식 아님.

Teams 열린 화면·웹 검색, Outlook 웹·Windows Search 색인은 보충 경로로 남습니다. 화면에서 읽은 몇 건으로 전체 기간 완료를 판정하지 않습니다.

Graph는 같은 계정·기간으로 다시 실행하면 미완료 지점을 이어갑니다. 요청 제한(429)·일시적 서버 오류는 재시도하고, 권한 오류·시간 소진은 사유를 남깁니다. 파일 가져오기는 고정 10,000건 상한을 제거하고 JSONL을 순차 처리합니다.

조회 중 새 메시지·삭제·권한 변경까지 한 시점의 완전한 스냅샷으로 보장하지는 않습니다. Graph 완주 후 재실행하면 새 조회를 시작하며 기존 기록을 보존합니다.

4. 원문 전체 ≠ AI가 읽는 문맥

서버/COM/파일 경로에서 수집한 평문은 data/communication_originals에 보관합니다. 분석 문맥은 기본 4,000자, AI 요청은 신호당 기본 800자 발췌입니다. 본문 수집을 끈 경로에서는 본문을 보관하지 않습니다.

첨부파일의 내용, 삭제된 원문 복원, 수정 이력 전체 백업은 범위 밖입니다. AI가 미수집 내용을 기억하거나 채웠다고 간주하지 않습니다.

5. 테스트 PC에서 실행할 순서

Graph가 허용된다면

1
상단 시작일·종료일 선택.
2
메일·Teams 근거 확보 → 서버 원문 연결에서 승인된 앱 ID·테넌트 입력. 필요하면 채널·답글 선택.
3
설정 저장하고 Microsoft 로그인. 진행 로그의 주소·코드로 로그인.
4
메일·Teams만 수집 (웹 포함). 범위와 중단 이유 확인. 중단됐다면 같은 기간으로 재실행.

Graph가 차단된다면

1
메일: 기존 Outlook에 계정 또는 승인된 PST 열기. 필요한 기간까지 동기화한 뒤 수집.
2
새 Outlook의 PST 내보내기: 설정 → 파일 → 내보내기. 복사 방식으로 내보내고 기존 Outlook에서 열기. 설치·조직 지원 조건 확인.
3
Teams: 관리자에게 기간·계정에 맞는 채팅/채널/답글 원문 요청. 시간대·대화 ID·메시지 ID·원본 건수 포함.
4
지원 파일 경로와 본인 주소를 입력해 가져오기. 원본 건수 대조 선택 가능. 지정 형식 예시: CSV / JSON.

PST 자동 장착·직접 해독은 하지 않습니다. Purview HTML/XML과 개인 Teams messages.json은 지정 형식으로 변환해야 하며 자동 변환기는 포함되지 않습니다. 자료 보충 후 모은 자료 분석을 실행합니다.

경로확인하는 범위남는 공백
메일 Graph승인된 기본 사서함의 요청 기간 페이지온라인 보관함·공유/타인 사서함·영구 삭제·첨부 내용
Teams Graph채팅 + 추가 권한 시 가입 팀 채널·답글접근 불가 대화·외부 호스트 공유 채널·보존 기간 밖 자료
Outlook COM연결 저장소에서 현재 보이는 메일미동기화 서버 자료. 삭제/정크/임시보관/보낼편지함·가상/공용 폴더 제외
내보내기 입력선택한 파일의 원문·식별자·날짜·건수내보내기 자체에서 누락된 서버 원본
화면·색인·Copilot각 화면·검색·응답에서 관측한 단서전체 사서함/대화 확보, 원문 전체
실제 0건과 조회 실패로 인한 0건은 다릅니다.
로그인·권한·본문 읽기·파싱·저장 실패를 사유로 남깁니다. 수집 건수는 근무시간이나 업무 부재를 뜻하지 않습니다.
