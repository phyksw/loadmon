1. 배경 및 목적
로드모니터 LM24는 Windows PC에서 실행하여 메일·일정·Teams 대화의 일부, 파일·작업창·PC 활동 기록을 취득하고 업무 분류·활동 시간·투입량을 추정하는 정보처리 도구입니다. 수집 자료는 개인 PC에 저장하며, 기능과 설정에 따라 Microsoft 365와 팀 서버 또는 공유폴더에 접속합니다. 사전 보안 검토를 위해 실행 구성, 접근 대상, 취득 후 취합·필터·가공, 개인 PC 보관, AI 입력·응답, 팀 전송·열람 범위를 설명합니다. 검토팀이 각 경계의 정보 항목과 기존 통제의 적용 여부를 확인하고 필요한 보완 조건을 결정할 수 있도록 소스 확인 사실과 운영 확인 사항을 구분합니다.

2. 비고란
LM24 v24.0.18 고정 소스를 기준으로 작성했습니다. 실제 운영망·계정·테넌트 정책·승인 상태는 미확인입니다. 분석에서 제외하거나 텍스트를 짧게 만드는 처리는 원자료·기존 AI 입력·팀 보관본의 삭제 또는 전체 익명화를 보장하지 않습니다. 기본 팀 서버에는 업로드·조회 사용자 인증과 HTTPS가 구현되어 있지 않습니다. 실제 실행 계정, 대상 폴더, 송신 허용 정보, 열람 권한, 암호화, 보존·삭제 및 백업 통제는 운영부서 확인 후 확정해야 합니다. 가상 검토팀의 문서 검토는 회사의 보안 승인 또는 침투시험을 대체하지 않습니다.

A 개발 인프라 유형
A1 웹 [해당]
개인 화면은 로컬 HTTP 웹 UI이며, 팀서버도 웹 보고서·API를 제공함. 인터넷 공개 웹사이트라는 뜻은 아님.
A2 모바일 [기본 미해당]
모바일 앱·모바일 전용 실행 환경의 구현은 확인되지 않음.
A3 SaaS [조건부]
Microsoft 365 Copilot·Outlook·Teams 웹 서비스를 연동할 때 해당. LM24 자체는 로컬 설치형임.
A4 서버·네트워크·DB·정보처리·보안 솔루션 [해당]
업무 활동을 처리하는 정보처리 도구. 선택적으로 Python 팀서버 사용. 별도 DB 서버·보안 솔루션을 제공하지는 않음.
A5 방화벽 룰 변경·DNS 신청 [조건부]
팀서버 접근·외부 Microsoft 서비스 접속 정책에 따라 신청 필요. DNS는 IP 주소 사용 시 필수가 아님.
A6 RPA·AI·자동화 도구 [해당]
PowerShell/Python 수집 자동화, Edge 화면 제어, Copilot AI 판정·정제를 포함함.
A7 CLI 전용 도구 (웹 UI 없음) [기본 미해당]
BAT·CLI 진입점도 있지만 웹 UI가 있으므로, 제시된 “웹 인터페이스가 없음” 조건에는 해당하지 않음.

B 사용되는 네트워크
B1 외부망 오픈 [조건부]
M365 웹·Copilot·Graph 사용 시 PC→외부 서비스의 송신 접속 필요. 인터넷→LM 팀서버 공개 수신은 필수 구성이 아님.
B2 그룹사망 (LG net) [확인 필요]
실제 PC·팀서버 위치와 라우팅을 코드로 판단할 수 없음. 운영 담당자가 확인할 항목.
B3 사내망 (OA망) [확인 필요]
팀 PC·공유폴더 사용 가능 구조이나 OA망이라는 실제 망 구분은 확인 필요.
B4 생산망 (FA망) [확인 필요]
FA망 설비 연동의 고유 기능은 미확인. FA망 PC·파일 경로에서 운영할 계획이 있는지는 확인 필요.
B5 외부 API 연동·입력 전달 [조건부]
Teams Graph API는 설정·권한 충족 시 사용. AI 정제는 직접 ChatGPT API가 아니라 Copilot 웹 입력이며, API 여부와 무관하게 업무 정보가 외부 서비스로 전달됨.

C 애플리케이션 운영 환경
C1 기존 Cloud 계정 [확인 필요]
LM24를 AWS/Azure에 배포하는 필수 구성은 없음. 별도 클라우드 운영 계획 확인 필요. M365 사용만으로 이 항목이 자동 해당하지는 않음.
C2 신규 Cloud 계정 [확인 필요]
신규 AWS/Azure 계정 생성 기능·필수 요구 없음. 실제 신청 계획 확인 필요.
C3 워크스테이션·로컬 PC·전산실 PC [해당]
Windows PC에 프로그램·내장 Python·수집/분석 파일을 두고 실행하는 기본 구조.
C4 온프레미스 데이터센터·DMZ [확인 필요]
가산 DC·상암 DMZ 등 실제 설치 위치는 코드에 근거가 없음. 팀서버 설치 계획 확인 필요.

D 개발자·개발 위치
D1 VDI PC 개발 [확인 필요]
소스만으로 VDI 사용 여부를 판단할 수 없음.
D2 로컬 PC 개발 [확인 필요]
Windows 로컬 개발·시험이 가능한 코드 구조. 실제 개발 단말이 로컬인지 VDI인지는 담당자 확인 필요.
D3 자사 개발 인력 [확인 필요]
개발자의 고용·소속은 코드로 확인할 수 없음.
D4 외주 개발 인력 [확인 필요]
CNS 등 외주 참여 여부는 프로젝트 담당자 확인 필요.
D5 사내 상주 개발 [확인 필요]
개발자의 실제 근무 장소 확인 필요.
D6 사외 원격 개발 [확인 필요]
사외 원격 개발 참여 여부 확인 필요.

E 개발언어
E1 웹 표준 (Java·Spring·React 등) [해당]
웹 화면에 HTML·CSS·JavaScript 사용. Java·Spring Boot·React 프레임워크 사용은 확인되지 않음.
E2 Python [해당]
분석·수집·AI 연결·개인 웹 UI·팀서버가 Python 기반. Django·ML 학습 라이브러리를 필수로 사용하지 않음.
E3 모바일 개발언어 [기본 미해당]
Android Java·Kotlin·Objective-C·Swift 기반 모바일 구현은 확인되지 않음.
E4 패키지 솔루션 특화 언어 [기본 미해당]
SAP HANA·Oracle 특화 개발 구조는 확인되지 않음.
E5 그 외 언어 [해당]
PowerShell(.ps1), Windows 배치(.bat) 사용. 브라우저 History 조회에는 SQLite SQL을 사용함.

F 처리하는 개인정보
F1 주민등록번호 (13자리) [확인 필요]
전용 수집 필드는 없음. Teams 화면 원문·제목·업무 텍스트에 섞여 있을 경우 처리될 수 있어 실제 자료 확인 필요.
F2 여권번호 [확인 필요]
전용 수집은 미구현. 자유텍스트 혼입 여부와 제외 정책 확인 필요.
F3 운전면허번호 [확인 필요]
전용 수집은 미구현. 자유텍스트 혼입 여부와 제외 정책 확인 필요.
F4 외국인등록번호 [확인 필요]
전용 수집은 미구현. 자유텍스트 혼입 여부와 제외 정책 확인 필요.
F5 계좌번호 [확인 필요]
전용 수집은 미구현. 메일 제목·채팅·업무 근거에 포함되는지 확인 필요.
F6 카드번호 [확인 필요]
전용 수집은 미구현. 자유텍스트 혼입 여부와 제외 정책 확인 필요.
F7 비밀번호 (일방향 암호화 대상) [확인 필요]
LM 자체 로그인 암호 필드는 없으나 자유텍스트 내 비밀번호 혼입 여부는 미확인. 원문 전체의 비밀번호 불포함·해시 저장을 보장하지 않음. Edge 세션·Graph 토큰도 별도 인증정보 검토 필요.
F8 주소 [확인 필요]
주소 전용 수집 필드는 없음. 일정 위치·화면 텍스트에 주소가 포함될 수 있어 확인 필요.
F9 생체인식 정보 [기본 미해당]
얼굴·지문·음성 등 생체인식 취득·인식 기능은 확인되지 않음.
F10 임직원명·사번·이메일 [해당]
owner/이름, 메일 상대·본인 계정, Teams 참여자, 문서 작성자, 업무 근거에 식별정보 포함 가능. 사번의 전용 수집 필드는 없음.
F11 전화번호·휴대폰·IP·MAC [조건부]
팀서버 사용 시 IP를 통신·로컬 요청 판별에 사용. 선택 라이선스 수집의 server/host에도 IP가 들어갈 수 있음. 전화·MAC 전용 수집은 미확인, 전화는 텍스트 혼입 가능.
F12 쿠키정보 [해당]
전용 Edge 프로필에서 로그인 세션·쿠키를 취급함. LM이 쿠키 값을 분석 CSV로 추출하는 기능과는 다름. “개인정보 없음”은 선택하지 않는 것이 타당함.

G 처리하는 중요 정보
G1 고객사 중요 정보 [조건부]
고객·제품·과제명, 파일명, 메일/채팅 발췌에 고객 중요 정보가 포함될 수 있음. 계약·정보등급 기준으로 확정 필요.
G2 사내 중요 정보 [조건부]
내부 프로젝트·설계/업무명, 활동 시각, 개인별 MM·부재/야근 추정·업무 흐름 등을 처리함. 회사 정보등급에 따라 판정 필요.
G3 중요 정보 없음 (일반 정보) [기본 미해당]
제목·요약·통계라는 이유만으로 일반 정보로 단정할 수 없음. 실제 내용·분류 기준 확인 전 일괄 체크 부적절.

H 인프라 정보
H1 서버·DB [조건부]
HTTP 팀 업로드 사용 시 Python 팀서버 필요. 공유폴더 취합은 별도 팀 HTTP 서버 없이 가능. 업무 저장은 CSV/JSON 파일이며 별도 DB 서버 없음. 브라우저 이력의 로컬 SQLite는 읽음.
H2 방화벽 룰 등록·변경 [조건부]
팀 클라이언트→서버 지정 TCP 포트(기본 9310), 외부 M365 HTTPS 송신의 기존 허용 여부에 따라 필요.
H3 네트워크 장비 [확인 필요]
신규 스위치·라우터 요구는 코드에 없음. 망간 연결·장비 변경 필요성은 실제 구성 확인.
H4 DNS 등록·변경 [조건부]
IP 주소로 운영 가능. 별도 도메인·HTTPS 프록시 주소를 사용할 때 신청 여부 확인.
H5 네트워크 보안 장비 [확인 필요]
웹방화벽·방화벽 장비를 코드가 제공하지 않음. 팀서버 보호 구성과 회사 정책에 따른 검토 필요.
H6 보안 솔루션 [확인 필요]
암호화·DLP·접근제어 솔루션이 제품에 내장됐다고 볼 근거 없음. 기존 보안 솔루션 적용 및 추가 도입 여부 확인.
