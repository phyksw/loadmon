4-2. 병목 순위

  1. 측정 설계 — 평면 차트 한 자세 (C 항). 촬영마다 다른 차트 거리·롤·위치 오차를 PB-A 가 fx·회전·시프트로 흡수했다 (왜곡 오차의 81–99.8 %, 실제 배치 오차와 배율 0.155 %, 롤 0.0005° 이내 일치). 원리적으로 분리 불가 → 판정은 4자유도 닮음변환을 뺀 값으로(D3a), 랩 촬영에는 콜리메이터 같은 절대 기준이나 두 번째 차트 자세가 필요하다.
  2. 표현력의 바닥 (R 항) — v1 렌즈 상태. 왜곡 k1..k3 다항식은 정답에 맞춰도 6P 4.7–5.8 px 가 남는다 (채널별 spline 이면 0.04 px). 필드 6 노드 선형 보간은 MTF50 오차 p90 0.52–0.80 (33 노드면 0.02–0.05). v1 규약(이상 상고, 이상 좌표 PSF, 픽셀 적분 2회)이 MTF 오차 0.15–0.29 를 만든다 — Zernike 차수 한계(≤ 0.05)보다 훨씬 크다.
  3. 코너 외삽 (X 항). 고정 검정 데이터의 측정 창이 r ≈ 0.973 에서 끝나 코너(r = 1)는 외삽이다: relaxed 5.7 px, 6P 9.1 px, 미학습 설계 zoo_r6_f25 25 px.
  4. 추정기 (E 항). v0 는 1000×750 축소 미리보기만 보고 원해상도·디포커스 창을 쓰지 않는다 → MTF RMS 0.35–0.41. 미학습 차트(Siemens) 처리 불가. 6매 설계에서 가짜 틸트 0.085–0.097°.
  5. 복원 연산자 (PB-B v0). 정답 상태로도 relaxed 코너 과선명(MTF50 비 1.17), 6P 중·외곽 복원 부족과 링잉(0.40–0.63) → G3 실패, 6P 는 G4 도 실패.
  6. 식별성. 디포커스 5면이면 7매 설계는 Zernike 부호가 모두 정해지지만, 6매 설계는 80 필드 중 10 필드(주로 축상)가 여전히 모호 → 미세 점 패널이 필요.
  7. 계산·운영. slim_6p 렌더 0.95 창/초 (target 3.1), 고정 데이터 생성 11.8 GPU-시간, BSOD 이력 때문에 무거운 작업은 한 번에 하나씩(가드), 그리고 LLM 토큰 사용량.

5. 설계 방향 비교 (relaxed vs 6P)

정답 상태로 복원해도 6P 는 relaxed 보다 차트 9.2 dB, 장면 7.7 dB 낮다 (45.7/43.9 vs 36.5/36.2 dB). TTL 축소는 relaxed −5.3 %, 6P −8.9 %. 두 설계 모두 MTF 가 0 에 가까운 대역(복원 불가 성분)은 없었다 → 6P 의 차이는 원리적 한계가 아니라 현재 연산자·표현의 한계다. 현재 수치는 팀의 relaxed 우선 판단을 지지한다.

6. 봉인 테스트 (미학습 렌즈·차트, 통과/실패만 공개)

두 slim 설계 모두 G2·G3·G4·G5 와 보고 목표(PSNR ≥ 36 dB) 실패. G1 은 test 복원 세트에 dot 차트가 없어 측정 불가 (iteration 1 에서 보완 예정). G5 의 모든 셀 실패. val 과 test 가 같은 양상이고 iteration 0 은 아무것도 튜닝하지 않았으므로 과적합 신호는 없다. 수치는 봉인 폴더에만 있다.

8. 현재 진행 — iteration 1

목표: 기하(왜곡·배율색수차)·셰이딩(RI) 규약과 표현력 교정 — LensState v2 (실제 상고, 채널별 spline 왜곡·RI, 센서 좌표 PSF, 픽셀 적분 1회), 차트 종류와 무관한 중심 측정으로 PB-A 기하·RI 추정 (Siemens 차트에서도 처음으로 수치), PB-B 채널별 리맵·RI 이득·센서 좌표 PSF 전달.
예상: 왜곡·RI 오차 70 % 이상 감소, 차트 PSNR +2–3 dB 이상. 선예도(MTF)는 iteration 2 (블러 재구축 + 5면 위상복원)에서 다룬다. 이번 회차는 학습 요소가 없어 재학습 없음.
진행 상태: 제안 2건·판정·LensState v2 계약 완료. 토큰 절약 방식으로 전환해 평가기·PB-A v1·PB-B v1 을 순서대로 구현 중이며, 측정은 사람 개입 없는 스크립트로 실행한다.

이 보고서는 집계 수치만 담는다. 내부 R&D 용 장면 사진과 봉인 테스트 수치는 포함하지 않았다.
