# LM25 분석 반복·PC 이동 속도 개선 검증

2026-09-09~10. 개발 대상은 `LoadMonitor25/`이며 LM24 기준선은 변경하지 않았습니다.

이 문서는 최초 속도 개선 시점의 기록입니다. 이후 이동 ZIP을 PC 이동 준비에 통합하고 PC 자료·월간 리뷰·워크플로우 표시를 보완했습니다. 현재 동작과 검증은 [회귀 보완 기록](LM25_REGRESSION_RECOVERY.md)을 따릅니다.

## 반영한 동작

- 각 로컬 PC에서 수집만 하고 마지막 PC에서 **모은 자료 분석**을 실행하는 흐름을 안내하고 UI에 연결했습니다.
- **이동 ZIP 만들기**와 `LoadMonitor25-빠른이동.bat`을 추가했습니다. 설정·자료·보고서·내장 Python은 보존하고 전용 브라우저 프로필·개발 캐시는 제외합니다. 원본은 수정하지 않습니다.
- 전송 중 원본 변경·잠금·링크·기존 출력 충돌을 검사하고 ZIP 내부 SHA-256을 확인합니다. 다음 PC에서 다시 ZIP을 만들 수 있으며 중지는 미완성 ZIP만 정리합니다.
- UI에서 ZIP 생성과 다른 변경 요청을 직렬화하고 샘플러 재시작과 양방향으로 겹치지 않게 했습니다. 취소는 메모리 신호로 전용 작업에만 전달하며 제어 파일을 만들지 않습니다. 일반 앱 종료에서도 ZIP 작업이 임시 파일 정리를 마치도록 기다립니다.
- 기존 PC 이동 준비의 용량 표시용 재귀 탐색 3회를 제거했습니다. 이 스크립트의 기존 종료·이름 변경 동작은 실제 PC에서 실행하지 않았습니다.
- 같은 PC·경로에서 24시간 이내의 정상 완료본을 명시적으로 재사용할 수 있습니다. 과거 기간, 입력·설정·코드·결과 내용, 단계 완료 증거가 일치해야 합니다. 부분/실패/스텁 응답, 변경된 설정·결과, 공유/자동 업로드는 재사용하지 않습니다.
- 최근 실행의 오래 걸린 단계와 시간을 UI에 표시합니다. `--no-teams`가 Graph 수집에도 적용되도록 누락된 조건을 수정했습니다.

## 수행한 검증

`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Test-Project.ps1` 결과 **PASS, 실패 관문 0개**.

- Python·JSON·TOML, Ruff, PowerShell 문법, BAT/PS1 인코딩·줄바꿈, 실제 PAGE/TEAM_PAGE JavaScript 통과.
- 내장 Python 3.11.9, TEMP 기본설정 복제본의 필수 파일 71개와 FILES.txt 크기·CRC32 일치, 기존 7관문 통과.
- 회귀 테스트 69개 중 **68개 통과, 1개 건너뜀**. Windows 심볼릭 링크 생성 권한이 필요한 사례이며 실제 junction 사례는 별도로 통과했습니다.
- 이동 자료 보존·프로필 제외·재압축·변경/잠금/출력 충돌·취소, UI 실행 옵션·동시 요청·취소 범위, 완료본 등록→다음 실행 AI/프로세스 추가 호출 0을 합성 사례로 확인했습니다.
- 이동 BAT에서 `--root <TEMP 합성 폴더> --plan --json` 실행 성공: 합성 파일 1개만 계획에 포함, ZIP 생성 없음.
- 독립 검토에서 발견한 잘못된 Agentic 배열 원소의 캐시 등록, 캐시와 같은 이름을 가진 사용자 자료 누락을 수정했습니다. 구현자와 다른 에이전트가 실패 사례를 다시 실행해 등록 거절·변경 검출·자료 보존을 확인했습니다. 메모리 취소, 샘플러 경쟁 방지, 정상 종료·Ctrl+C 취소 전달도 독립 검증했습니다.
- `review_runtime_probes.py`를 새 실행기와 UI 구조에 맞춰 갱신했습니다. `--no-teams` 및 잘못된 JSON 요청의 실행 상태 고착은 더 이상 재현되지 않았습니다. 다른 기존 설계 결함 3개는 그대로 재현되며 해결했다고 주장하지 않습니다.

검사 로그: `verification/lm25-check-20260910-000033-912.txt` (로컬 검증 기록).

실제 수집·회사 계정 로그인·Copilot·업로드·UI/팀 서버는 실행하지 않았습니다. 변경은 로컬 작업본에 반영했으며 배포 ZIP 발행이나 이번 변경의 Git 푸시는 수행하지 않았습니다. 전체 기능 설계 검토의 나머지 항목은 [LM25_FULL_DESIGN_REVIEW.md](LM25_FULL_DESIGN_REVIEW.md)에 남아 있습니다.
