# LM24 사전 보안 검토 자료

타 부서의 검토자가 **어디에서 실행되고, 어떤 정보를 취득·저장하며, 취합·필터·가공 뒤 AI와 팀에 무엇을 보내는지** 확인하기 위한 자료입니다.

분석 기준은 `lm24` 브랜치의 **v24.0.18**, 커밋 `53f78e5fb53f075e583a2618319c96e0ffaae44b`입니다. 이 문서 전용 브랜치는 LM25 개발 저장소에서 분기했으며 제품 소스는 수정하지 않습니다. LM24 실행 코드를 이 브랜치에 복사하지 않습니다.

## 최종 사용본

먼저 제출용 PDF를 읽고, 세부 항목은 두 HTML 및 질의·답변 기록에서 확인할 수 있습니다.

- [외부 검토팀 제출용 PDF](v3/03_LM24_사전보안검토_제출용.pdf): 본문 8쪽, 체크리스트 5쪽, 운영 확인표 2쪽, 신청서 문안 1쪽. 총 16쪽, 페이지 책갈피 제공.
- [인프라 아키텍처 HTML](v3/01_LM24_인프라아키텍처.html): 실행 계기·계정·프로세스·자동 관측·연결·저장·통제 및 체크리스트.
- [데이터 흐름도 HTML](v3/02_LM24_데이터흐름도.html): 취득부터 취합·필터·업무/시간 처리·AI·팀 집계까지. 가상 메일 한 건의 정보 변화와 상세 필드 표 포함.
- [제출용 HTML](v3/03_LM24_사전보안검토_제출용.html): 제출 자료의 상세 열람본.
- [가상 검토팀 질의·답변·수정 기록](v3/04_가상검토팀_질의답변_및_검증기록.html): 24개 질의·지적, 근거 답변, 수정 위치, 독립 재검토 판정.
- [신청서 기입 문안 TXT](v3/신청서_기입문안_및_체크리스트.txt): 배경 및 목적, 비고, A–H 48항목.
- [검증 결과 JSON](v3/검증결과.json), [상세 질의·재검토 기록 JSON](v3/질의답변_검토기록.json).

HTML·JSON·PDF 파일은 같은 폴더에 내려받으면 문서 사이 링크를 사용할 수 있습니다. PDF는 단독 열람 가능합니다. 실제 외부 검토팀에 전송한 것은 아닙니다.

## 독립 검토와 수정 과정

초안 작성 → 보안·가독성 검토자의 독립 질문 → 코드 검증자의 고정 소스 대조 → 본문·도표 수정 → 2차 재검토 → 남은 두 항목 및 도형 범례 보완 → 3차 해당 부분 재확인을 수행했습니다. 보안·가독성 검토자는 처음에 자료만 읽고 질문했으며, 코드 검증자와 역할을 나눴습니다.

고유 질의·지적 **24건 중 문서 설명상의 의문 18건을 해소**했습니다. 실제 운영 증빙이 필요한 **6건은 확인 대기**입니다. 실제 기능·계정·망·주소, 팀 접근·전송 보호, M365 정책, 정보 허용·정정, 저장 보호, 보존·파기는 운영부서가 담당자·확정일·증빙을 채워야 합니다. 가상 검토는 회사 보안 승인 또는 침투시험이 아닙니다.

주요 보완 내용은 다음과 같습니다.

- 수집 이후 취합·기간·중복·대상·제외어와 업무/시간의 별도 처리 경로를 도식화했습니다.
- 파일 내용힌트 캐시가 신호 제외어 검사 전에 생성될 수 있고, 분석 제외가 원자료·기송신본 삭제를 의미하지 않음을 명시했습니다.
- UI 상태 조회에서 관측기가 시작될 수 있고 정상 수집 중 로그온 작업을 등록하는 기본 경로, UI 종료 후 관측 가능성을 추가했습니다.
- AI 판정의 시간 재산정 실패 가능성과 업무행 정제의 총 MM 유지·비중 재배분을 구분했습니다.
- 추가 PC 보관이 CSV 선별에 한정되지 않고 해당 수집 하위폴더 전체를 옮길 수 있음을 제출본에도 반영했습니다.
- AI 입력의 상대 표기 축소와 팀 전송의 추가 가림 부재를 같은 가상 메일 사례로 연결했습니다. 사람의 보고서 검토가 필수 전송 승인 관문은 아닙니다.
- 팀 수신 후 저장·집계·재업로드·기간 불일치·개인별 열람 범위를 설명했습니다.

## 검증 범위와 한계

고정 소스를 재독해하고 선택 AST 함수와 메모리 합성 자료를 검증했습니다. 수집·로컬 저장 4묶음, AI·팀 전송 계약 4건, 취합·필터 사례 26건, 분석·AI·팀 사례 5건, 후속 코드 사례 3건이 통과했습니다. 서로 다른 검증 단위이며 전체 제품 시험 건수로 합산하지 않습니다.

HTML 구조·문서 링크·48개 체크 항목·인라인 JavaScript 구문·독립 SVG 도형의 문자 범위를 검사했습니다. HTML 브라우저 화면은 도구의 로컬 파일 URL 정책으로 검증하지 못했습니다. 별도 작성한 PDF는 16쪽 전체를 이미지로 확인하고, 수정한 5쪽을 다시 확인했습니다. PDF 검증을 HTML 화면 검증으로 간주하지 않습니다.

회사 계정·개인 설정·실제 수집자료·운영망·Copilot·팀 서버를 실행하거나 조회하지 않았습니다. 저장소 회귀 게이트는 문서 브랜치의 제품 코드 보존 확인이며 LM24 실연동 성공이나 보안 적합성을 뜻하지 않습니다.
