A 개발 인프라 유형

항목선택 권고판단 근거 / 기입 설명
A1 웹☑ 해당개인 화면은 로컬 HTTP 웹 UI이며, 팀서버도 웹 보고서·API를 제공함. 인터넷 공개 웹사이트라는 뜻은 아님.
A2 모바일☐ 기본 미해당모바일 앱·모바일 전용 실행 환경의 구현은 확인되지 않음.
A3 SaaS△ 조건부Microsoft 365 Copilot·Outlook·Teams 웹 서비스를 연동할 때 해당. LM24 자체는 로컬 설치형임.
A4 서버·네트워크·DB·정보처리·보안 솔루션☑ 해당업무 활동을 처리하는 정보처리 도구. 선택적으로 Python 팀서버 사용. 별도 DB 서버·보안 솔루션을 제공하지는 않음.
A5 방화벽 룰 변경·DNS 신청△ 조건부팀서버 접근·외부 Microsoft 서비스 접속 정책에 따라 신청 필요. DNS는 IP 주소 사용 시 필수가 아님.
A6 RPA·AI·자동화 도구☑ 해당PowerShell/Python 수집 자동화, Edge 화면 제어, Copilot AI 판정·정제를 포함함.
A7 CLI 전용 도구 (웹 UI 없음)☐ 기본 미해당BAT·CLI 진입점도 있지만 웹 UI가 있으므로, 제시된 “웹 인터페이스가 없음” 조건에는 해당하지 않음.

신청서 기입 문안

1. 배경 및 목적

로드모니터 LM24는 개인 Windows PC에 남는 파일·Git·작업창·PC 가동 기록과 Outlook 메일·일정, Teams 대화 등 업무 활동 근거를 수집·분석하여 업무별 투입량(MM), 업무 구조와 자동화 검토 대상을 파악하는 도구입니다. 취득 자료는 개인 PC에 저장하며, 일부 대체 수집과 선택한 AI 정제 단계에서 Microsoft 365 Copilot 웹을 사용합니다. AI 정제에는 업무 신호와 근거 일부가 전달됩니다. 팀 기능 사용 시 개인별 신호·분석 결과를 지정 팀서버 또는 공유폴더로 전송하여 팀 단위로 취합합니다. 본 검토는 단계별 저장·전송 정보와 인프라 경계를 명확히 하여 운영·개인정보·정보보호 사전검토에 활용하는 것을 목적으로 합니다.

2. 비고란

분석 기준은 Git lm24 브랜치 v24.0.18(53f78e5)이며 LM25 기능은 포함하지 않았습니다. 기본 설정과 구현을 분석한 자료로, 실제 회사 계정의 수집 성공·전체 기간 수집 완전성·운영망·접근 정책을 검증한 결과는 아닙니다. 개인 PC에는 수집 CSV 외 Teams 화면 원문, AI 프롬프트/응답, Edge 로그인 프로필 및 일부 임시 자료가 남을 수 있습니다. AI 전송은 단계별로 신호 발췌·과제/업무명·근거·일부 MM/비중/건수를 포함하며 완전한 비식별 처리를 보장하지 않습니다. 팀 전송에는 개인 식별정보, 신호 CSV와 분석 파일이 포함됩니다. 기본 팀서버는 HTTP 및 업로드/조회 인증 미구현 구조이므로 망 접근 제한·인증·암호화·보존/파기 기준을 별도로 검토해야 합니다. 개발자 소속·실제 개발 환경·OA/LG net/FA망·데이터센터 위치·M365 테넌트 정책은 운영 담당자 확인이 필요합니다.
