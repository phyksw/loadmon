로드모니터 LM24 사전검토 신청서 기입 문안
기준: lm24 / v24.0.18 / 53f78e5fb53f075e583a2618319c96e0ffaae44b
분석일: 2026-10-02
실제 회사 자료·계정 접근 없이 정적 코드 분석. LM25 기능 미포함.

1. 배경 및 목적
로드모니터 LM24는 개인 Windows PC에 남는 파일·Git·작업창·PC 가동 기록과 Outlook 메일·일정, Teams 대화 등 업무 활동 근거를 수집·분석하여 업무별 투입량(MM), 업무 구조와 자동화 검토 대상을 파악하는 도구입니다. 취득 자료는 개인 PC에 저장하며, 일부 대체 수집과 선택한 AI 정제 단계에서 Microsoft 365 Copilot 웹을 사용합니다. AI 정제에는 업무 신호와 근거 일부가 전달됩니다. 팀 기능 사용 시 개인별 신호·분석 결과를 지정 팀서버 또는 공유폴더로 전송하여 팀 단위로 취합합니다. 본 검토는 단계별 저장·전송 정보와 인프라 경계를 명확히 하여 운영·개인정보·정보보호 사전검토에 활용하는 것을 목적으로 합니다.

2. 비고란
분석 기준은 Git lm24 브랜치 v24.0.18(53f78e5)이며 LM25 기능은 포함하지 않았습니다. 기본 설정과 구현을 분석한 자료로, 실제 회사 계정의 수집 성공·전체 기간 수집 완전성·운영망·접근 정책을 검증한 결과는 아닙니다. 개인 PC에는 수집 CSV 외 Teams 화면 원문, AI 프롬프트/응답, Edge 로그인 프로필 및 일부 임시 자료가 남을 수 있습니다. AI 전송은 단계별로 신호 발췌·과제/업무명·근거·일부 MM/비중/건수를 포함하며 완전한 비식별 처리를 보장하지 않습니다. 팀 전송에는 개인 식별정보, 신호 CSV와 분석 파일이 포함됩니다. 기본 팀서버는 HTTP 및 업로드/조회 인증 미구현 구조이므로 망 접근 제한·인증·암호화·보존/파기 기준을 별도로 검토해야 합니다. 개발자 소속·실제 개발 환경·OA/LG net/FA망·데이터센터 위치·M365 테넌트 정책은 운영 담당자 확인이 필요합니다.

첨부 1. 인프라 아키텍처
개인 Windows PC, 로컬 웹 UI·저장소, Microsoft 365 연결과 선택적 팀서버/공유폴더의 배치·포트·접근 경계를 설명합니다.
첨부 2. 데이터 흐름도
취득→개인 로컬 저장→신호/시간 산출→AI 정제→전송 대기→팀서버/공유폴더 취합의 데이터 수준을 구분합니다.

Microsoft 365 Copilot·Outlook·Teams 웹 서비스를 연동할 때 해당. LM24 자체는 로컬 설치형임.
A4 서버·네트워크·DB·정보처리·보안 솔루션 [해당]

A5 방화벽 룰 변경·DNS 신청 [조건부]
팀서버 접근·외부 Microsoft 서비스 접속 정책에 따라 신청 필요. DNS는 IP 주소 사용 시 필수가 아님.
A6 RPA·AI·자동화 도구 [해당]
PowerShell/Python 수집 자동화, Edge 화면 제어, Copilot AI 판정·정제를 포함함.
A7 CLI 전용 도구 (웹 UI 없음) [기본 미해당]
BAT·CLI 진입점도 있지만 웹 UI가 있으므로, 제시된 “웹 인터페이스가 없음” 조건에는 해당하지 않음.

B2 그룹사망 (LG net) [확인 필요]
실제 PC·팀서버 위치와 라우팅을 코드로 판단할 수 없음. 운영 담당자가 확인할 항목.
B3 사내망 (OA망) [확인 필요]
팀 PC·공유폴더 사용 가능 구조이나 OA망이라는 실제 망 구분은 확인 필요.
B4 생산망 (FA망) [확인 필요]

B5 외부 API 연동·입력 전달 [조건부]
Teams Graph API는 설정·권한 충족 시 사용. AI 정제는 직접 ChatGPT API가 아니라 Copilot 웹 입력이며, API 여부와 무관하게 업무 정보가 외부 서비스로 전달됨.
