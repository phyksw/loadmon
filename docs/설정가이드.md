# AgentFinder32 설정 가이드

설정은 **`config\config.json`** 한 파일입니다. 배포본의 `config\config.json` 과 `config\config.default.json` 은 같은 내용이고,
`config.default.json` 은 처음 값을 보려고 두는 사본입니다. 메모장으로 열어 고치고 UTF-8 로 저장하면 다음 [분석 실행]부터 반영됩니다.
기본값 그대로 두어도 됩니다 — 받은 사람이 꼭 볼 것은 §1 세 가지뿐입니다.

JSON 규칙 세 가지만 지키세요.
- 글자는 큰따옴표 `"..."` 안에 적습니다.
- 항목 사이에는 쉼표 `,` 를 두고, 마지막 항목 뒤에는 두지 않습니다.
- 경로의 백슬래시는 두 번 적습니다 → `"config\\restricted_customers.json"`.

`_설명` 처럼 `_` 로 시작하는 키는 설명이라 읽지 않습니다. 옛 LoadMonitor 의 `config.json` 을 옮겨 오지 말고 배포본에서 시작하세요.

**분석 기간·보관기한·익명 팀 집계 문턱은 더 엄격하게만 바꿀 수 있습니다.** 이 상한과 문턱은 프로그램이 지킵니다. 범위를 넘는 값은
잘라 쓰고, 그 사실을 화면과 실행 기록(`report\run_meta_*.json` 의 `config_warnings`)에 남깁니다(§9).

**바꾸면 메일·일정을 처음부터 다시 읽는 설정** — 정제 규칙이 바뀌므로 지난 정제 파일을 지우고 다시 모읍니다: `privacy.*`(문의처는
빼고) · `storeMailSubject` · `calendar.collectBody` · `noticeSenders` (제한 고객 목록 파일이 바뀔 때도 같습니다).

### 서면 동의서와 읽는 범위를 넓히는 설정

이 도구는 서면 동의서를 낸 사람만 씁니다. 동의는 서면으로 따로 받으며, 이 도구는 동의를 묻거나 기록하지 않습니다.
설정을 바꿔도 이 도구는 다시 묻지 않습니다. 아래 설정은 읽거나 남기거나 보내는 범위를 넓히므로, 서면 동의서가 그 항목을 다룰 때만 켭니다.

| 넓어지는 것 | 설정 |
|---|---|
| 읽는 곳을 더합니다(Outlook 앱 · Outlook 웹 · 회사 M365 Copilot) | `collect.channels` |
| 회의 본문(안건)을 모읍니다 | `calendar.collectBody` |
| 모은 안건을 가린 뒤 Copilot 에 보냅니다 | `calendar.bodyToAI` |
| 메일 제목을 가린 뒤 이 PC 에 남깁니다 | `storeMailSubject` |

- 운영 담당은 배포하는 설정이 서면 동의서와 맞는지 확인합니다. 넓히려면 서면 동의서를 먼저 다시 받습니다(`docs\운영기준.md` §5-1).
- 지금 설정대로의 안내는 `python\python.exe -X utf8 core\consent.py --notice` 로 볼 수 있고, 서면 동의서에 붙일 수 있습니다. 화면의
  [안내]가 보이는 글과 같습니다.

### config.json 에 없는 것

| 무엇 | 어디서 바꾸나 |
|---|---|
| 조직장 팀 서버 주소·포트·참여 코드 | `AgentFinder32-팀서버주소.bat` 에서만(`config\af32_team_server.json` 에 저장). 화면 [공유] 탭은 보여 주기만 합니다 |
| 제한 고객 목록 | 운영 담당이 나눠 주는 `config\restricted_customers.json`(형식은 `config\restricted_customers.example.json` · §4-2). 제한 고객의 이름은 배포하는 `config.json` 에 적지 않습니다 |
| 과제 이름 지정 | 화면 [업무 분류] 탭의 '과제 이름 지정' 카드(`config\projects.json` 에 저장 — 이 PC 에서만 쓰고 공유 자료에서는 가립니다) |

## 1. 먼저 볼 것

| 키 | 기본값 | 설명 |
|---|---|---|
| `owner` | `""` | 본인 이름. 제목 속 내 이름을 [사람]으로 가리고, 나에게 보낸 내 메일을 두 번 세지 않는 데 쓰며, [공유] 탭 이름 칸의 기본값입니다 |
| `function` | `""` | 소속 파트. 업무 분류 표의 Function 칸과 [공유] 탭 파트 칸의 기본값으로 씁니다 |
| `privacy.internalDomains` | `[]` | 회사 메일 도메인(예 `["corp.example"]`). 내 주소의 도메인과 합쳐 사내 판별에 씁니다. 비어 있고 내 주소도 모르면 분석하지 않습니다 |

운영 담당이 `privacy.internalDomains` 를 채운 `config.json` 을 나눠 줍니다.

- 도메인 형식이 아닌 값은 빼고 경고를 남깁니다. 공용 개인 메일 도메인은 적어도 사내 도메인으로 쓰지 않고 경고를 남깁니다.
- 전용 Edge 의 Copilot 창에 로그인한 계정의 도메인도 이 목록이나 내 메일 주소의 도메인에 있어야 합니다. 없으면 Copilot 에 보내지
  않습니다(사유 `R-ACCOUNT`). 로그인 도메인이 메일 도메인과 다른 회사는 그 도메인도 여기에 넣습니다.

## 2. 분석 기간

| 키 | 기본값 | 설명 |
|---|---|---|
| `period.maxDays` | `92` | 분석 기간의 최대 일수. 1~92일 안에서 더 짧게만 바꿀 수 있습니다 |

- 끝날은 늘 어제입니다. 오늘은 넣지 않습니다.
- 화면의 1개월은 30일, 3개월은 92일입니다(어제부터 거슬러). 날짜를 직접 고를 수도 있습니다.
- 더 긴 기간을 고르면 끝날은 두고 시작날을 뒤로 밀어 92일로 줄이며, 줄였다는 사실을 화면과 리포트에 알립니다.
- 분석할 때마다 기간 밖의 자료는 뺍니다.

## 3. 수집

| 키 | 기본값 | 설명 |
|---|---|---|
| `collect.channels` | `["com", "owa", "copilot"]` | 읽는 곳 — `com` Outlook 앱(이 PC 의 내 기본 사서함) · `owa` Outlook 웹(전용 Edge 창, 내가 로그인) · `copilot` 회사 M365 Copilot(회사 테넌트에서 내 사서함 목록). 이 셋 안에서만 고릅니다. 서면 동의서가 다루는 경로만 켭니다 |
| `collect.cursorEpoch` | `1` | '어디까지 읽었는지' 기록의 세대 번호. 1 올리면 기간 전체를 처음부터 다시 읽습니다(화면 [커서 초기화], `python run.py --reset-cursors` 와 같습니다) |
| `collect.mailAllPaths` | `false` | true 면 앞 경로가 기간을 확인했어도 Outlook 웹을 기간 전체로 돌려 합칩니다 |
| `collect.mailTimeOffsetH` | `0` | 웹·Copilot 경로의 메일 시각이 UTC 로 기록될 때 더할 시간(−24~24) |
| `outlook.subfolders` | `true` | Outlook 앱에서 받은·보낸 편지함의 하위 폴더까지 읽습니다(기본 사서함만) |
| `outlook.attachWaitSec` | `120` | Outlook 이 바쁘다고 답할 때 다시 붙어 보는 최대 초 |
| `outlook.ostStaleH` | `72` | 최근 달의 가장 새 메일이 이 시간보다 오래됐으면 오프라인 사본이 멈춘 것으로 보고 그 달을 '다 읽음'으로 표시하지 않습니다 |
| `outlookBudgetSec` | `0` | Outlook 앱 수집 한 회차의 시간 예산(초). 0 = 자동(240 + 60 × 개월, 360~900). 못 읽은 달은 다음 실행이 이어서 읽습니다 |
| `owaExtraFolders` | `true` | Outlook 웹에서 받은·보낸 편지함 말고 내가 만든 폴더·하위 폴더·보관 폴더도 목록만 읽습니다(메일을 열지 않습니다). 폴더 창에서 내 사서함임이 확인될 때만 읽고(내 메일 주소가 보이거나, 선택된 받은 편지함을 품은 사서함), 공유·위임 사서함의 폴더는 읽지 않습니다 |
| `owaExtraFolderMax` | `40` | 위 폴더를 한 번에 읽는 최대 개수 |
| `owaExtraFolderSkip` | `[]` | 읽지 않을 폴더 이름(일부만 적어도 됩니다). `privacy.excludeMailFolders` 의 폴더는 이것과 상관없이 늘 뺍니다 |
| `calendar.collectBody` | `false` | 회의 본문(안건)을 모을지. 서면 동의서가 회의 본문을 다룰 때만 켭니다 |
| `calendar.bodyToAI` | `false` | 모은 안건을 가린 뒤 Copilot 판정의 참고로 보낼지. 두 키를 모두 켜야 쓰입니다. 서면 동의서가 이것을 다룰 때만 켭니다 |
| `calendar.noteMaxChars` | `160` | 회의 한 줄에 붙이는 안건 글자 수 상한(20~600) |
| `calendar.tentativeMeetings` | `"count"` | 미정·미응답 초대 — `count` 셉니다 · `skip` 뺍니다 · `response` 수락한 회의만 |
| `storeMailSubject` | `true` | 메일 제목을 가린 뒤 이 PC 에 남겨 업무 분류에 씁니다. false 면 제목을 남기지 않아 분석이 거의 되지 않습니다. 서면 동의서가 제목 저장을 다룰 때만 true 로 둡니다 |

- 메일 본문과 첨부 파일은 어느 설정으로도 읽지 않습니다. Outlook 웹의 목록에 함께 보이는 미리보기 글도 쓰지 않습니다.
- Outlook 웹 경로는 받은 메일의 받는 사람과 회의 참석자 주소를 볼 수 없습니다. 그 경로로 읽은 받은 메일과 회의는 늘 빼고 보낸 메일만
  남깁니다. 받은 메일과 회의는 Outlook 앱이나 Copilot 경로로 읽습니다.
- Outlook 웹이 읽은 날도 받은 메일은 읽은 날로 치지 않습니다. `collect.channels` 에 `copilot` 이 있으면 그 날의 메일 목록을 Copilot 에
  묻습니다(Copilot 이 이미 답한 날은 다시 묻지 않습니다).

## 4. 개인정보 규칙

아래 키는 규칙을 **더하기만** 합니다. 규칙을 끄는 키는 없고, 예외 키(`privacy.sensitiveFilter.allowWords` ·
`privacy.allowPatterns`)는 업무 표현을 개인정보로 잘못 본 것만 바로잡습니다.

| 키 | 기본값 | 설명 |
|---|---|---|
| `privacy.restrictedCustomersFile` | `"config\\restricted_customers.json"` | 제한 고객 목록 파일. 없거나 형식이 틀리면 분석·공유를 하지 않습니다 |
| `privacy.excludeCategories` | `["개인", "Personal", "Private", "사적"]` | 빼는 Outlook 범주 이름(일부만 적어도 됩니다). 적은 이름은 기본 이름에 더해집니다 — 목록에서 기본 이름을 지워도 그 범주는 늘 뺍니다 |
| `privacy.excludeMailFolders` | `["개인", "Personal", "Private", "사적"]` | 빼는 메일 폴더 이름. 적은 이름은 기본 이름에 더해집니다 — 목록에서 기본 이름을 지워도 그 폴더는 늘 뺍니다 |
| `privacy.excludeKeywords` | 개인 주제어 13개 | 빼는 개인 주제어(개인·가족·사생활·이력서·자소서·면접·이직·병원·의료·보험·연말정산·자격증·취미). 한글은 부분 일치, 영문은 단어 일치. 적은 낱말은 기본 낱말에 더해집니다(기본 낱말은 지워도 늘 씁니다) |
| `privacy.sensitiveFilter.extraWords` | `[]` | 민감정보로 더 볼 낱말 |
| `privacy.sensitiveFilter.allowWords` | `[]` | 민감 낱말이 든 업무 표현의 예외(예 '보건관리자 교육'). 공학·업무 문맥 낱말(시스템·설계·장비·교육 등)이 든 표현만 받습니다. 그런 낱말이 없는 표현과 2자보다 짧은 표현은 받지 않고 `config_warnings` 에 남깁니다 |
| `privacy.customers` | `[]` | 고객사 이름 — 이 PC 안에서만 쓰고 분석과 공유 자료에서 가립니다 |
| `privacy.partners` | `[]` | 협력사 이름 — 위와 같습니다 |
| `privacy.codenames` | `[]` | 과제 코드네임 — 공유 자료에서 늘 가립니다 |
| `privacy.maskCodenames` | `false` | true 면 분석에서도 과제 코드네임을 [과제]로 바꿉니다 |
| `privacy.allowPatterns` | `[]` | 식별번호·코드로 잘못 보이는 공학 코드 표기(예: 부품 번호 형식)의 정규식. 맞는 부분이 공학 코드 꼴(숫자나 영문 대문자가 든 표기)일 때만 가리지 않습니다. 주민·외국인등록·카드·전화·메일 주소·계좌 형태나 고객사·과제·사람 이름 같은 보통 낱말에도 맞는 넓은 식, 빈 글에 맞는 식, 200자보다 긴 식, 형식이 틀린 식은 받지 않고 `config_warnings` 에 남깁니다. 주민·카드·계좌 번호, 전화·메일 주소, 고객사·과제·사람 이름은 이 식과 상관없이 늘 가립니다 |
| `privacy.contact.name` | `""` | 문의처의 이름(예 '운영 담당 OOO', 40자까지). 운영 담당이 채워 배포합니다. 화면의 [안내]와 [내 데이터] 탭에 보이고, 비어 있으면 '이 도구를 배포한 운영 담당'으로 보입니다(`docs\운영기준.md` §11) |
| `privacy.contact.channel` | `""` | 문의처의 연락 방법(예 사내 메신저·메일 주소, 120자까지). 운영 담당이 채워 배포합니다 |
| `nonWorkKeywords` | 업무가 아닌 낱말 22개 | 업무 실체가 없는 항목(취소 회의, 자동 회신, 발송 실패 알림 등)을 신호 단계에서 뺍니다. 대소문자 무시. 적은 낱말은 기본 낱말에 더해집니다(기본 낱말은 지워도 늘 씁니다) |
| `noticeSenders` | 공지 발신자 낱말 26개 | 공지·시스템 발신자 — 수집 직후 공지로 표시해 업무 근거에서 뺍니다. 회신한 적이 있는 발신자는 공지로 보지 않습니다. 회사 알림 계정은 받은 사람이 더합니다 |

### 4-1. 설정과 상관없이 늘 켜진 규칙

읽은 직후 아래 항목은 빼고 저장하지 않습니다. 몇 건을 뺐는지만 [수집·제외 현황] 탭에 보입니다.

- Outlook 의 비공개·개인·기밀 표시, 개인 범주·폴더·주제어가 든 항목
- 휴가·연차·반차·병가·근태·출장·외근·재택·부재 같은 행방 항목(신청·승인 포함)과 종일·한가함·부재중·취소·거절 일정은 늘 뺍니다
- 건강·노동조합·정치·종교·성생활·범죄 경력 같은 민감한 내용이 든 항목
- 가린 뒤에도 주민등록번호·외국인등록번호·여권·운전면허·카드·계좌 번호 같은 식별 번호가 남는 항목, 비밀번호·인증번호 같은 접속 정보가 든 항목
- 사외 사람이 하나라도 있거나 모든 참여자가 사내인지 확인할 수 없는 메일·회의
- 제한 고객 목록의 고객사(이름·약칭·메일 도메인)와 관련된 항목

남기는 항목은 이렇게 가립니다.

- 전화번호·메일 주소와 주민등록번호·카드·계좌 같은 번호는 [전화]·[이메일]·[주민번호]·[카드]·[계좌] 같은 표시로 바꿔 둡니다.
- 사람 이름은 이 도구가 알아보는 것만 [사람]으로 가립니다 — 메일·회의 참여자로 본 이름과 '홍길동 책임'처럼 호칭·직함이 붙은 한글
  이름입니다. 그 밖의 이름(참여자로 보지 못했고 호칭·직함도 없는 이름, 영문 이름 등)은 그대로 남을 수 있습니다.
- 같은 이름을 다음 분석에서도 가리려고 이름 조각을 열쇠로 바꾼 값(해시)만 이 PC 에 둡니다. 그 이름을 마지막으로 본 날부터
  `retention.intermediateDays` 가 지나면 지웁니다(남은 분석 결과와 함께 둔 것은 `retention.resultDays` 까지).
- 보낸 사람은 이름·주소 대신 부호(p:…)로 바꿉니다. 이 부호를 만드는 열쇠는 이 PC 에만 둡니다.

옛 판의 규칙 끄기 키(사외 메일 포함·민감도 끄기 등)를 적어 두면 무시하고 경고를 남깁니다.

### 4-2. 제한 고객 목록 파일의 형식

운영 담당이 `config\restricted_customers.example.json` 의 형식으로 `config\restricted_customers.json` 을 만들어 나눠 줍니다.

- `confirmed` — 목록을 확인한 날(`YYYY-MM-DD`). 앞날이나 날짜가 아닌 값은 받지 않습니다.
- `customers` — 고객사 목록. 고객사마다 `name`(이름)·`aliases`(약칭·영문 이름)·`domains`(메일 도메인)를 적습니다. 이름과 약칭은 2자 이상이고,
  이름이나 도메인 가운데 하나는 있어야 합니다. 제한 고객이 없으면 빈 목록으로 둡니다.
- 이름은 메일 제목에 쓰는 이름으로 적습니다. 회사 형태((주)·주식회사 등)는 붙이지 않아도 됩니다 — 붙여 적으면 뗀 이름도 함께 찾습니다.
  3자 이상 이름은 띄어쓰기나 하이픈이 달라도 찾습니다.
- 모르는 키, 같은 키를 두 번 적은 것, 견본을 그대로 복사한 파일(`_template` 줄이 남은 것)은 받지 않습니다. `_` 로 시작하는 그 밖의 키는
  설명이라 읽지 않습니다.
- 받지 않을 때는 분석과 공유를 하지 않고 틀린 곳을 알립니다. 목록을 확인한 날과 지문(파일 해시 앞 8자)은 [수집·제외 현황] 탭에 보입니다.

  메뉴를 쓸 때 · 조직장 PC 의 매일 정리 예약 작업이 지웁니다. 자세한 것은 `docs\운영기준.md` §4.
- 서버 두 값은 조직장 PC 의 `config.json` 에서 정합니다. 팀원 PC 는 서버가 이 상한보다 길게 둔다고 하면 보내지 않고, 보내기 전 확인
  창에는 그 서버가 말한 보관기한을 보입니다.
- 보관 일수로 지우지 않는 것은 `docs\운영기준.md` §4-1 에 있습니다.
- `data\purge_status.json`(마지막 자동 정리의 날짜·건수와 지우지 못한 파일의 경로)과 `data\run.lock`(분석이 도는 동안의 잠금), `data\task_state.json`(매일 정리 예약 작업을 설정에 맞춘 날)은 이 도구가
  쓰는 작업 파일입니다.

## 8-2. Copilot 이 「요청이 너무 많다」고 할 때

- `copilotAuto.throttleWaitSec`(기본 120): 사용량 제한을 알리면 이 초만큼 한 번 쉬고 같은 묶음을 한 번만 다시 보냅니다. 그래도 막히면 이번 실행의
  AI 단계를 멈추고 여기까지의 결과를 지킵니다. 0 이면 쉬지 않고 바로 멈춥니다.
- `copilotAuto.minGapSec`(기본 15): 질문 사이의 최소 간격(초). 0 이면 끔.
- `copilotAuto.runWaitMaxSec`(기본 300): 한 번의 분석에서 Copilot 때문에 쉬는 시간의 합계 상한(초). 다 쓰면 그 단계의 남은 묶음은 보내지 않고
  여기까지의 결과를 지킵니다. 1~2시간 뒤 다시 실행하면 남은 것만 이어서 합니다.

| `keepAwakeDuringRun` | `true` | 분석이 도는 동안 PC 가 절전(잠자기)에 들어가지 않게 합니다. 화면 꺼짐·화면 보호기·잠금은 평소대로입니다 |

- 화면은 이 PC 의 브라우저에서만 열립니다(`http://127.0.0.1:<포트>`, 포트 9370~9389 중 빈 것).
- 화면은 `AgentFinder32-UI.bat` 이 연 주소로 들어온 브라우저에서만 열립니다. 주소만 따로 입력하거나, 이 PC 의 다른 계정·다른 프로그램이
  접속하면 열리지 않고 까닭만 보입니다. bat 을 다시 실행하면 새로 띄우지 않고 열려 있는 화면으로 이어집니다.

## 8-4. 창을 닫으면 작업도 멈춥니다 — 그래도 남으면 `AgentFinder32-강제종료.bat`

- 화면 탭을 모두 닫으면 약 20초 뒤 도는 작업을 멈추고 끝납니다. 새로고침(F5)·최소화·다른 탭·화면 보호기·잠금은 닫은 것으로 보지 않습니다.
  스스로 끝났으면 그 까닭이 `report\ui_exit.json` 에 남고 다음에 화면을 열 때 한 번 알립니다. 끄려면 `uiAutoExit` 를 false 로 둡니다.
- 화면 보호기가 돌거나, 화면이 잠겨 있거나, 키보드·마우스 입력이 3분 넘게 없는 동안에는 화면에서 신호가 오지 않아도 닫은 것으로 보지
  않습니다. 이 확인은 그 순간에 이 PC 안에서만 하고 어디에도 적지 않습니다.
- 자료를 지우는 작업이 도는 동안에는 창을 닫아도 끝까지 한 뒤에 끝납니다.
- 검은 콘솔 창의 X 를 누르면 분석·수집 프로그램과 전용 Edge 도 함께 끝납니다.
- 조직장 팀 서버(`teamserver.py`)는 화면을 닫아도 그대로 둡니다. 서버 창에서 Ctrl+C 로 끕니다.

**'응용 프로그램을 제대로 시작하지 못했습니다(0xc0000142)'** — 수집기(PowerShell)가 켜지는 순간 Windows 가 초기화에 실패한 것입니다
(보안 프로그램이나 Windows 자원 문제). 이 도구가 띄우는 프로그램에는 이 오류 창이 뜨지 않고, 3초·8초 쉬었다가 두 번 다시 띄웁니다.
그래도 안 되면 그 단계를 건너뛰고 진행 로그에 까닭을 남깁니다. 같은 줄이 되풀이되면 PC 를 다시 시작한 뒤 실행하세요.

**그래도 작업이 남은 것 같을 때** — `AgentFinder32-강제종료.bat` 을 더블클릭하면 묻지 않고 이 폴더의 작업(화면·분석·수집기·전용 Edge·그 콘솔 창)을
모두 끝내고, 끝내기 전과 뒤의 목록을 보여 줍니다. PowerShell 이 끝내 켜지지 않으면 파이썬이 같은 규칙대로 직접 끝냅니다.
사람이 쓰는 Edge·Chrome, 다른 폴더의 사본, 팀 서버는 건드리지 않습니다. 팀 서버까지 끄려면 명령 창에서
`AgentFinder32-강제종료.bat -IncludeTeamServer`, 끝내지 않고 목록만 보려면 `-Status` 를 붙입니다. 관리자 권한이 필요 없습니다.

## 9. 코드가 정한 것 — 설정으로 바꿀 수 없음

| 규칙 | 값 | 설정으로 |
|---|---|---|
| 분석 기간 상한 | 92일 | `period.maxDays` 로 더 짧게만 |
| 분석 끝날 | 어제(오늘은 넣지 않음) | 바꿀 수 없음 |
| 수집 자료 보관 | 30일 | `retention.rawDays` 로 더 짧게만 |
| 중간 자료 보관 | 30일 | `retention.intermediateDays` 로 더 짧게만 |
| 분석 결과 보관 | 90일 | `retention.resultDays` 로 더 짧게만 |
| 개인 리포트 보관 | 90일 | `retention.htmlDays` 로 더 짧게만 |
| 공유 사본 보관 | 30일 | `retention.shareDays` 로 더 짧게만 |
| 서버의 개인 리포트 보관 | 90일 | `retention.serverPersonalDays` 로 더 짧게만 |
| 서버의 익명 기여분 보관 | 180일 | `retention.serverTeamDays` 로 더 짧게만 |
| 익명 집계 최소 참여 인원 | 5명 | `team.minGroupSize` 로 더 크게만 |
| 후보 이름 최소 제안 인원 | 3명 | `team.minCellSize` 로 더 크게만 |
| Copilot 은 회사 계정으로만 | 늘 켜짐 | `copilotAuto.requireWorkAccount` 는 늘 true |
| Copilot 채팅 주소 | `https://m365.cloud.microsoft` 의 주소만 | `copilotAuto.url` 에 다른 주소를 적으면 기본 주소로 |
| Copilot 창의 계정 확인 | 늘 켜짐 — 회사 도메인의 계정일 때만 보냄 | 바꿀 수 없음(회사 도메인은 `privacy.internalDomains` 로 더함) |
| 수집 경로 | Outlook 앱 · Outlook 웹 · M365 Copilot 의 메일·일정만 | `collect.channels` 는 이 셋 안에서만 |
| 설정을 바꿀 때 다시 묻기 | 하지 않음 — 서면 동의서로 따로 받음 | 바꿀 수 없음(읽는 범위를 넓히는 설정은 서면 동의서가 다룰 때만 켬) |
| 개인정보 규칙(§4-1) | 늘 켜짐 | 더하기만 |
| 공유 | [공유] 탭에서 고를 때만 · 자동으로 다시 보내지 않음 | 바꿀 수 없음 |
| 화면 포트 · 전용 Edge 포트 · 팀 서버 기본 포트 | 9370~9389 · 9573 · 9390 | 화면 포트는 바꿀 수 없음 |
| 화면을 여는 곳 | `AgentFinder32-UI.bat` 이 연 주소로 들어온 브라우저만 | 바꿀 수 없음 |
| 조직장 화면을 사내망에서 열기 | HTTPS 로 켠 팀 서버에서만 | `team.remoteView` 는 HTTP 서버에서 쓰이지 않음 |

범위를 넘는 값이나 형식 오류는 위 값으로 잘라 쓰고, 화면과 `report\run_meta_*.json` 의 `config_warnings` 에 한국어 문장으로 남깁니다.

## 무엇부터 하면 되나

1. 운영 담당이 준 `config\restricted_customers.json` 을 넣고, `privacy.internalDomains` 가 채워져 있는지 봅니다.
2. `owner`·`function` 을 적습니다(선택).
3. `AgentFinder32-UI.bat` → [AI 연결 진단]으로 전용 Edge 에서 회사 계정 로그인 → [분석 실행].
4. 결과가 이상하면 [업무 분류] 탭의 '과제 이름 지정'으로 과제 이름을 알려 주고 다시 분석합니다.
5. 나머지 설정은 기본값 그대로 둡니다.
