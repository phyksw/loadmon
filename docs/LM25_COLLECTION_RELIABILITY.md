# LM25 수집 신뢰성 개선과 v25.5 회귀 보완

## v25.5 — Teams·Outlook 0건 제보 후 확인한 결함

2026-09-30. 실제 실행 PC/폴더가 아직 확인되지 않았고, 연결된 PC에서 LM25 실행 로그는 발견되지 않았습니다. 다음은 기존 코드와 비교하여 합성 TEMP 환경에서 재현한 결함과 수정입니다. 제보 PC에서 정상 수집됨을 확인했다는 뜻은 아닙니다.

- Outlook의 새 CSV 저장 helper가 배치 실행기의 `py -3` 지원과 달랐습니다. 실행 중 Python의 절대경로를 자식 수집기에 전달하고, 단독 실행에서도 정상 Python 3.11+를 찾아 저장하도록 수정했습니다. launcher-only 경로의 COM·색인 누적 저장을 실제 PowerShell 프로세스로 검증했습니다.
- `DefaultStore.GetRootFolder()` 실패가 직접 접근 가능한 받은편지함·보낸편지함까지 버리게 했습니다. 두 기본 폴더를 먼저 독립적으로 확보하고, 나머지 범위는 부분 수집으로 남깁니다. 합성 COM 객체로 CSV 2건 보존과 완료 판정 금지를 검증했습니다.
- Teams 앱에서 별도 날짜 구분선을 읽지 않아 과거 기간 대화가 오늘 날짜로 제외됐습니다. 날짜 구분선·명시된 헤더 날짜를 해석하고, 기간 옵션 없는 상시 샘플러에는 새 90일 필터를 적용하지 않습니다. 미확인 날짜를 요청 기간으로 임의 보정하지 않습니다.
- Teams 웹의 그룹방 이름 비교와 전환 대기를 보강했습니다. 이전 방의 메시지 수 변화가 성공 조건이 되지 않으며, 전체 방 제목 또는 식별자가 맞아야 메시지를 읽습니다.
- 추가 본문에 기본 제외 단어가 있을 때 정상 제목·요약 신호까지 제거됐습니다. 본문만 `context_filtered`로 제외하며, 원래 제목·요약 필터와 비업무 판정은 유지합니다. 기본 설정을 사용한 실제 mine → 모의 judge → refine 경로에서 안전한 신호 보존과 차단본문 미전달을 검증했습니다. 수집 CSV의 0건과 분석 단계의 0건은 별개입니다.
- 프로세스 실패가 `blocked`/`failed`를 무조건 `partial`로 바꾸던 상태 표시와 Outlook 웹·색인·Copilot을 모두 COM으로 표시하던 안내를 수정했습니다. 진단기의 `-SavedOnly`는 저장된 건수·기간·상태만 확인하고 COM·UIA·브라우저 경로 전에 종료합니다.

구현자와 다른 작업자가 Outlook helper, Teams 파서·대화 전환, 본문 필터, 실행 Python 전달, 진단 모드, 상태 보존을 독립 검토했습니다. Teams에서는 반복 날짜/방 제목을 전역 중복 제거하면 다른 날짜·대화로 잘못 귀속되는 문제도 추가 재현하여 수정했습니다. 파싱 입력의 순서·반복 구조를 보존하고 실제 창 경계에서 날짜·방을 초기화하며, 메시지 중복 제거는 저장 단계에서 수행합니다. 실제 PowerShell 재생 3사례와 경계 초기화·저장 중복 제거·반복 원문 보존을 독립 재확인했습니다.

## 구현

- `core/collection_state.py`: 출처 식별자와 보수적인 레거시 매칭, 원자적 CSV 누적 저장, 요청 기간·시각을 검증하는 상태 파일.
- `core/communication.py` 및 `run.py`: 단계 성공·CSV 시각 대신 명시된 수집 범위로 보충 여부 결정. 메일/일정 개별 판정, 예산·옵션·중단 이유 기록, 프로세스 실패 시 완료 판정 강등.
- Outlook 수집기: 기본 저장소 메일 폴더 탐색, 제한된 본문 발췌, 폴더 범위 변경에 따른 완료 표 갱신, 선택적 웹 본문 읽기, 모든 보충 결과 누적 저장.
- Teams 수집기: Graph 페이지·오류·상한 판정, 웹 가상 목록과 과거 기간 탐색, 페이지별 저장, 날짜 포함 중복 키, 앱 확장 CSV 읽기와 시간 정밀도 표시.
- 추출/분석/정제: 기존 표시문·식별자 호환성을 유지하면서 문맥·출처 별도 전달. AI 입력 예산과 생략 표시. 추정을 사실로 복원하지 않도록 지시.
- UI: 요청 기간과 일치 여부, 경로별 상태·범위·이유 표시. 독립 활동 기간 조회에서도 상태 표 유지.

## 독립 검토에서 보강한 사례

같은 ID에 짧은 보충 본문이 긴 본문을 덮는 문제, 동명 Teams 대화의 서로 다른 대화 ID가 합쳐지는 문제, 날짜만 있는 보충 관측이 정확한 시각을 덮는 문제를 합성 자료로 재현해 수정했습니다. 프로세스가 실패해도 완료 체크포인트를 믿는 경로와 활동 기간 조회가 범위 표를 지우는 경로도 보강했습니다.

Git pre-commit 내부의 합성 저장소 테스트가 부모 저장소 환경을 상속하는 결함도 수정했습니다. staged snapshot 검사는 유지하고, 그 내부 테스트 프로세스에만 Git의 로컬 저장소 환경변수를 제거합니다. 부모 index 보존 회귀를 추가했습니다.
