3. 무엇을 읽고, 필터 전에 무엇이 남는가

Teams발신자·대화명·시각·짧은 발췌, 앱 화면 텍스트정규화된 메시지 CSV에서 빠진 화면 문구가 별도 텍스트에 남을 수 있음
파일·Git·작업창·PC경로·이름·작성자·활동 시각·내용 단서·창 제목·프로세스단순 건수보다 넓은 업무·개인 식별 단서가 포함될 수 있음

4. 취합한 자료를 어떻게 거르고 바꾸는가

취합·필터는 분석 대상을 결정합니다. 원자료 삭제와 개인정보 전체 익명화를 수행하는 단계는 아닙니다.

처리입력과 규칙출력·남는 정보
취합·형식 정리현재 PC·추가 PC 파일의 날짜·출처·상대·텍스트를 읽고 공백·개행 등을 정리형태가 같은 분석 후보. 이름·상대·업무 내용이 자동 익명화되지는 않음
기간·중복요청 기간과 자료별 중복 키 적용기간 밖·중복은 이번 분석에서 제외. 원본 파일 일괄 삭제 아님
대상·제외어설정 제외어, 공지·단체발송, 취소·거절 등 대상별 규칙일부는 분석 제외, CC·열람 등은 약한 단서로 반영 가능. 민감정보 전량 탐지 아님
신호·계산 변환텍스트 발췌, 업무 묶기, 활동 구간·가중치·설정 적용D2의 신호·업무 분류·시간/MM·근거. 신호 텍스트는 기본 최대 100자
AI 결과 반영judge는 신호 비업무 제외 후 시간 재산정 시도; refine은 업무행을 정리둘 다 원자료 삭제 절차가 아님. refine 행 제외는 총 MM을 유지하고 비중 재배분
  • 이 표는 처리 기능을 묶은 설명입니다. 실제로는 각 출처를 읽으며 중복·기간·대상 규칙을 적용합니다.
  • 분석 중 접근 가능한 일부 파일에서 짧은 내용 단서를 추가로 읽어 data/files/file_hints.json에 캐시합니다. 신호의 제외어 검사보다 앞이며, 이후 제외해도 캐시 삭제를 뜻하지 않습니다.
  • 파일 내용 단서에서 제외어가 발견되어 신호가 빠져도, 별도 파일 시각은 시간 근거로 남을 수 있습니다.
  • AI 신호 판정은 시간 재산정을 시도하지만 실패하면 이전 계산값이 유지될 수 있습니다. 제외 장부도 항상 남는다고 보장할 수 없습니다. 업무행 정제는 총량을 유지해 비중을 다시 나눕니다.

5. AI에는 어떤 입력이 나가고 응답은 어디에 남는가

코드가 선별한 입력을 Copilot 웹에 보내고, 응답을 다시 분석·보고서에 반영합니다.

단계외부 입력·응답D2 및 보호 경계
개별 신호 판정날짜·출처·상대 표기·텍스트 발췌 → 업무 여부·과제·세부업무분석 신호와 판정 결과. 텍스트 속 식별정보는 남을 수 있음
업무 정제·설명업무명·근거·비중·활동일수·표본 → 정리된 이름·설명요청·응답·설명 기록. 일부 경로에 MM도 포함 가능
업무 흐름·자동화 후보업무명·근거·통계 등 → 후보·흐름단계별 입력이 다르고 업무 흐름에는 MM·건수도 포함
팀 AI 정리과제·업무·후보 이름 목록 → 이름 묶기별도 개인 이름·MM 필드는 없지만 명칭 속 개인정보·기밀은 가능
취득 중 대체 조회메일·일정 조회 지시 → 메타데이터 응답분석 AI를 꺼도 기본 대체 조회에서 실행 가능. 조회 원응답은 D1에 남을 수 있음
  • 수집용 Copilot 조회는 분석용 필터보다 앞에서 실행될 수 있습니다. AI 정제를 끄는 것만으로 모든 외부 AI 조회가 차단되지는 않습니다.
  • judge는 기본 who 표기만 일부 축소합니다. 제목·본문 발췌의 인명·고객명·URL·IP를 전부 가리는 처리는 없습니다.

6. 팀에는 어떤 파일이 전달되고 누가 볼 수 있는가

팀 취합은 합계만 보내는 기능이 아니라, 개인별 신호와 분석 결과를 함께 보관·열람하는 기능입니다.

경로D2에서 전달하는 것D3의 결과·경계
HTTP 팀 업로드인원 정보 + 최대 9종 CSV·JSON 전체 텍스트를 JSON으로 전송이름·PC명·기간·수치·신호·설명·근거 포함 가능. 1회 30 MiB, ZIP 아님
표준 업로드 제외취득 폴더 전체·원문 TXT·프로필·토큰·원본 첨부·개인 HTML 제외그 안에서 추출된 텍스트는 신호·분석 결과에 포함될 수 있음
공유폴더 자동 복사설정 시 결과 CSV·JSON과 인원 정보 복사HTTP 자동 전송을 꺼도 별도 동작할 수 있음
수동 공유폴더 저장같은 결과와 원문이 포함될 수 있는 개인 HTML 추가파일 공유 권한자가 원문 포함 보고서를 읽을 수 있음
팀 집계·조회수신 파일로 팀 보고서 생성. 일반 집계는 AI 호출 없이 수행기본 업로드·조회 인증·HTTPS 없음. 토큰은 설치 확인용이며 인증 수단 아님
  • HTTP 자동 전송은 기본 꺼짐입니다. 업로드 대기 묶음은 로컬에 만들며, 공유폴더 자동 복사는 별도 설정에 따라 동작합니다. 사람의 보고서 검토 완료를 확인하는 필수 승인 관문은 없습니다.
  • 같은 사용자 이름(owner)으로 재업로드하면 해당 파일·인원 정보를 교체합니다. 다른 분석 기간을 자동으로 제외하는 팀 집계는 아니므로 기간 정합성도 확인해야 합니다.
  • 표준 업로드는 추가 익명화를 수행하지 않습니다. 누가 어느 개인 결과를 열람할 수 있는지는 실제 망·인증·폴더 권한으로 결정해야 합니다.

7. 구현된 제한과 운영으로 보완할 통제를 구분하기

키워드·길이·파일명 제한만으로 모든 저장물의 개인정보 보호와 접근통제가 완료되는 것은 아닙니다.

검토 대상현재 확인 사실운영부서 확인 필요
취득·분석 제한기간·중복·일부 키워드·대상 규칙·발췌 길이 제한자유텍스트 혼입, 제외 규칙의 실제 적용 범위, 기록 공백·오분류 검토
팀 접근·전송기본 HTTP·인증 미구현. 공유폴더 방식은 파일 접근권한에 의존허용 PC·망·사용자, 인증·HTTPS·폴더/보고서 권한 적용 방식
인증자료Edge 세션과 Graph 토큰 별도 보관. Graph 토큰은 평문 JSON·사용자 ACL 설정 시도권한 적용 결과·단말 보호·복사·진단 제출 제한·계정 종료 시 처리
보존·삭제D1·D2·D3와 인증·임시 사본에 서로 다른 기록 존재자료별 기간·삭제·백업·단말 교체·퇴직/업무 변경 시 처리. 분석 제외와 구분
