**공통 규칙**
- 반입은 사내 미러로만 합니다. npx·uvx 로 최신판을 받는 방식은 금지합니다.
- SDK 하한은 mcp>=2.2.0(또는 1.30.0)입니다.
- 실행은 stdio 가 기본입니다. HTTP 는 localhost 또는 mTLS 로 게이트웨이 뒤에 둡니다.
- 게이트웨이는 Agent ID 와 Mcp-Name 으로 도구별 인가를 강제합니다.
- C3 세션에서는 단계마다 노출하는 도구를 10~15개 이하로 둡니다(추정).
- 개발 PC 는 managed settings 의 allowManagedMcpServersOnly 와 C3 경로 deny 를 씁니다.
- 체크리스트 항목은 [OWASP MCP Top 10](https://owasp.org/www-project-mcp-top-10/) 분류를 따르고 근거는 [NSA CSI](https://www.nsa.gov/Portals/75/documents/Cybersecurity/CSI_MCP_SECURITY.pdf) (2026-05-20)로 표기합니다.

**담당**
- 반입 승인은 정보보안이 하고, A·B 가 판정합니다.
- 0단계 적합성은 해당 과제의 AI 엔지니어가 봅니다.
- 검증·재검토 실행은 MLOps 가 플랫폼 운영 안에서 합니다.
- 도메인 오너는 과제 DRI 개발자입니다.
- '29 H1 부터는 반입 승인을 정보보안 표준 절차로, 미러·스캐너 운영을 IT 로 넘기고, AX 는 규칙과 판정만 맡습니다.
