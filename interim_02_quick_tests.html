PB 렌즈 복원 — 중간 보고 2 (빠른 시험)

2026-11-09 · 기존 결과 파일만 사용 · 슬림 7P 렌즈 1유닛, 공칭, 노이즈 OFF · 대략치 · 봉인 시험 숫자 없음

0. 한눈에

요약
  1. 가장 큰 효과는 기하(왜곡) 보정이다. 점 위치 오차가 약 50 px 에서 약 0.2 px 로 줄고 PSNR 이 17~30 dB 오른다.
  2. RI(밝기) 보정도 잘 된다. 평탄장 오차 24 % 에서 0.3~0.5 % 로 내려간다.
  3. 지금 병목은 PSF(블러) 추정이다. 특히 모서리와, 목표 렌즈의 PSF 가 문제다.
  4. 5면 through-focus 방식(A3)이 중심·중간에서 가장 좋다. 모서리는 아직 실패한다.
  5. PSNR 은 방법 간 차이가 거의 없다(27.6~28.6 dB). 선예도(MTF50 비)는 0.61~1.16 으로 크게 다르다. 그래서 지표를 여러 개 쓴다.
  6. 동공(pupil) 모양 템플릿이 틀렸다. 동공 모양부터 추정하는 시험이 진행 중이다.

1. 목표와 PB 설계

요약
  1. 슬림 렌즈 사진을 7매 렌즈(target_7p) 사진처럼 복원하는 것이 목표다.
  2. 바뀐 점: 길고 한 번에 다 도는 실험 대신, 짧고 거친 시험으로 PB 의 어떤 부분이 중요한지 먼저 찾는다(요청 사항).
  3. PB-A 가 렌즈 상태를 추정하고, PB-B 가 그 상태로 복원한다.

2. 빠른 시험 1: 자세차 없음 vs 있음

요약
  1. 차트·센서 자세가 틀어졌을 때와 아닐 때를 비교했다.
  2. 기하 보정이 가장 크다. RI 보정은 평탄장을 고친다. PSF 전달은 PSF 가 정확해야 도움이 된다.
  3. 자세는 주로 절대 위치에 영향을 준다. 차트 자세를 빼면(D3a) 품질은 비슷하다. PB-A v1 은 차트 자세만 또는 센서 틸트만 줄 때 기하가 불안정했다.

3. 6P 줄무늬 진단

요약
  1. 6P 렌즈 바깥 영역에서 색이 있는 링잉(줄무늬)이 보였다.
  2. 원인은 대부분 PB-A 의 PSF 오차를 Wiener 이득(5~7배)이 키운 것이다.
  3. 이득 상한(gain cap)은 조금 돕는다. 근본 해결은 더 정확한 PSF 다.

4. 빠른 시험 2: PSF 추정 방법 비교

요약
  1. A0 미리보기 · A1 에지 MTF · A2 미세 점 · A3 5면 through-focus 를 참값과 비교했다.
  2. A3 가 중심·중간에서 최고다(Zernike 부호 해결, 오차 약 ±0.03 파장). 모서리는 실패한다.
  3. 허용오차: PSF MTF RMS 가 약 0.02~0.03 이하여야 MTF50 비가 0.95~1.05 에 든다.

5. 빠른 시험 3-4: 외곽 보강과 동공 모델

요약
  1. A3+ 는 r 0.8 에서 오차를 0.12 → 0.059 로 줄였다. 모서리는 약 0.13 으로 그대로다.
  2. 목표 렌즈 PSF 도 정확해야 한다. 틀리면 모서리가 덜 복원된다(MTF50 비 0.49). PB-B 링잉 대책(오차 인지 Wiener, 색 약화)은 효과가 없었다.
  3. 동공 모델 시험: 템플릿 동공 모양이 틀렸다(참 접선 배율 약 0.5, 템플릿 약 1.1~1.4). 동공 모양 먼저 추정하는 다음 시험은 진행 중이다.

6. 다른 SOTA 조사

요약
  1. 빠른 점검으로 11개 후보를 순위 매겼다(웹 초록 수준, 코드 미실행).
  2. 상위 5개와 시도 여부는 아래와 같다.
  • 1. PSF 오차 인지 Wiener — 시도, 이득 없음
  • 2. 도트 타깃 직접 비맹 PSF + 정칙화 — 미시도 (A2 와 유사)
  • 3. 미분 가능 Zernike + through-focus — 시도 (A3)
  • 4. 교차 채널 / 색 링잉 억제 — 일부 시도 (색 약화, 이득 없음)
  • 5. PSF 섭동 증강 학습 잔차 — 미시도 (학습 필요)

7. PB 로직 관계 정리

요약
  1. 각 단계가 무엇을 해 주고 지금 무엇이 막는지 한 장으로 본다.
  2. 초록 = 잘 됨, 노랑 = 막힘(동공 모델).
  3. PSF 만 맞으면 나머지는 이미 충분하다.

8. 학습 결과

요약
  1. 솔직히 말해, 이 루프에서 학습한 AI 부분은 아직 없다.
  2. 기하·RI·PSF 는 모두 물리 모델을 데이터에 맞춘 것(피팅)이다.
  3. 학습 계획: PSF 오차 보정용 소형 잔차 네트워크(후보 5번)는 물리 PSF 가 안정된 뒤에 시도한다.
